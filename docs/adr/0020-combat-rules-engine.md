# ADR-020: Combat rules engine — validated action resolution, effects, typed damage, and the dying state

## Status

Accepted — 2026-07-18. Amended the same day (second slice, same PR): reaction
prompts, incapacitation gating, the available-actions read, and archive v3 — see
"Amendment" below.

## Context and decision drivers

A forensic comparison of two archived runs of the same encounter (a manual GM run and a rules-aware recreation driven through the integration API) showed that the engine recorded mechanics but did not own them: the manual run performed two Frenzy attacks plus a Greataxe attack in one round-one turn with no Rage active, resolved Extra Attack as unrelated single rolls, applied crocodile damage to a raging barbarian with no resistance, never created the Bite grapple as state, and used seven manual heals (five of exactly 1 HP) as a stand-in for a dying state. None of this was blocked, warned about, or guided. The automated recreation proved the low-level API could emulate the rules — at a cost of 120 commands for a three-round fight, with the rules living in an external script instead of the server.

The owner's direction for this milestone: combat should "just work" — the legal action is the easiest path, unavailable actions are clearly explained, and the GM keeps an explicit, audited override for homebrew and intentional exceptions. This supersedes the earlier blanket posture that action economy is "tracked, never enforced" (ADR-008's reference level; BUILD_PLAN §13.4 "do not hard-block extra actions"), which these runs showed delegates too much rules bookkeeping to the GM's memory. Design precedent for the typed-mechanics vocabulary was validated against MIT-licensed sibling projects (notably cbgfx/beholden's typed-effects compendium schema) — patterns only, no code or data reuse.

## Considered options

- Keep reference-level tracking and improve display only: preserves the old posture but cannot prevent any of the observed error classes.
- A high-level "execute action" API that atomically rolls every attack, applies damage, and resolves prompts in one transaction (the gap-analysis report's original proposal): maximally guided, but reshapes the one-command-one-roll journal/archive contract, breaks replay of existing archives, and removes the GM's between-rolls target choice.
- Validated resolution over the existing command surface (chosen): `action.resolve` stays one roll burst per command, but validates against engine-owned state before rolling, with a per-encounter enforcement mode and an audited override.

## Decision

The server owns combat rules state and validates structured action resolution against it (extending ADR-008, whose representation rules are unchanged: declarative vocabulary, bounded dice grammar, no imported executable code).

1. **Structured mechanics vocabulary** (additive-optional on `ActorDefinition` schemaVersion 1, per ADR-007): `attack.count` (Extra Attack, beams), `attack.criticalBonusDice` (Savage Attacks), `multiattack` composition, `onHit` condition riders with escape DCs and size caps, `targetRules`, `grants` (self effects like Rage/Reckless with typed modifiers, durations, and on-end grants), `requiresEffectTag`, `uses` (per turn/encounter/long-rest with shared pools), and typed defense lists (`damageResistances`/`damageImmunities`/`damageVulnerabilities`/`conditionImmunities`). The SRD ETL emits these from confident statblock patterns only (126 of 178 Multiattacks, 47 on-hit riders, 146 monsters with typed defenses); everything else stays inert prose.
2. **Rules modes with an audited override.** Each encounter carries `rulesMode`: `strict` (default — invalid structured resolutions are rejected with machine-readable `blocked {rule, message, overridable}` details), `assisted` (allowed, conflicts logged as warnings), `freeform` (no checks). Any rejection can be bypassed by resending with `override: {reason}`, which is prominently recorded in the combat log (kind `override`) and the journal. An actor whose stat block has a prose-only Multiattack degrades action-slot violations to warnings even in strict mode — the engine never polices rules it cannot see. Manual commands (`turn.use`, amount-only damage, `actor.set-condition`, `actor.set-hp`) remain free escape hatches for the GM (a player's `actor.set-condition` is policed since the 2026-10-16 conditions amendment); un-marking the action slot also clears the open compound-action instance.
3. **Action instances.** Resolving an action-activation action with a free action slot consumes the slot once and opens an instance of remaining components: a generic `attack` pool for `attack.count` (so Extra Attack may legally mix weapons), actionId-keyed components for `multiattack` (Bite + Tail). Further resolves consume components; exhausted instances reject with "no attacks remaining". One command still equals one roll burst, preserving journal/archive semantics and sequential target choice.
4. **Persistent effects.** `Actor.effects` holds engine-owned `EffectInstance`s (name, tags, source links, duration, typed modifiers, linked conditions, escape DC, on-end grants, `endsWithTag` cascades). The engine ends them: durations expire at the source's turn start, a source at 0 HP releases what it sustains (grapples, its own Rage), `endsWithTag` cascades (a marker effect ends with the effect it depends on, firing its on-end grants exactly once), encounter end sweeps the fight's combatants (on-end grants fire — a documented simplification; since the 2026-10-16 conditions amendment only effects measured in turns or rounds), and grants from the same source actor + action refresh rather than stack. Sweeps are scoped to the current initiative so parked scenes keep their effects. On-hit riders auto-apply conditions at resolve time — the same owner-approved carve-out class as save auto-apply.
5. **Typed damage at apply time.** `actor.apply-damage` accepts optional typed `parts`; the server applies flat reductions → immunity → resistance-halving → vulnerability (resistance and vulnerability on one type both apply, halving first, per the SRD 5.2.1 Order of Application) from definition defenses plus active effects, then temp HP, and returns/logs the per-part breakdown ("17 bludgeoning → 8, resistance: Rage") — never a silent adjustment. The bare `amount` stays exact for manual corrections. Pending saves carry typed parts and halve the total once on success (rounded down, spread back over the types).
6. **Advantage aggregation with explanations.** Attack resolution aggregates advantage/disadvantage sources (effect modifiers — `attack-advantage` is evaluated only on the bearer's own turn, Reckless semantics; incoming-attack-advantage on the target; prone with the 2024 distance rule via authoritative token distance; restrained/poisoned/blinded/stunned/paralyzed/petrified/unconscious; unconscious + adjacent upgrades hits to crits), cancels per 5e, rolls `2d20kh1/kl1`, and reports every contributing source. An explicit GM `rollMode` choice wins.
7. **The dying state.** Damage dropping a player character to 0 applies Unconscious + Prone and initializes death saves (instant death on overflow ≥ max HP); damage while dying adds failures (two on a crit; stability breaks and counters restart from zero per the SRD reset rule); `death-save.roll` runs the d20 pipeline (20 → 1 HP + conscious; 1 → two failures; a total of 10+ after Exhaustion and save bonuses succeeds; three successes → stable with counters reset; three failures → dead), and in a fight a player commits one per turn, on the dying character's own turn; healing or set-hp above 0 clears the dying state (Prone stays). Non-player combatants at 0 are "defeated" (effects they sustain end; no death saves). All five HP entry points share this machine.
8. **Command surface.** New commands `effect.add`, `effect.end`, `death-save.roll`, `encounter.set-rules-mode`, `actor.rest` (long rest: effects end first, HP/uses/dying reset, Exhaustion −1) ride the shared operations layer, both transports, the OpenAPI contract, and the archive journal like every other command (ADR-016 no-fork). Timeline restores and the dirty comparator cover effects, death saves, spent uses, spell and Pact slots, and Hit Dice; player projections strip effect source ids, mask hidden source names, and expose limited-use spending only for the claimed character.

## Consequences and tradeoffs

The published `turn.use` semantics changed from "(tracked, never enforced)" to "manual toggle; structured resolution validates per rules mode" — integrations replaying old journals (or scripting freely) should set `freeform` mode first, and a mid-flight encounter upgraded under this release parses to `strict` and may see first rejections until the GM overrides or switches modes. Slot enforcement applies on the acting combatant's own turn; off it, an action or Bonus Action is the `economy.not-your-turn` block (since the 2026-10-16 action economy amendment), and reactions, legendary actions and a readied response are the off-turn activations. Prose-only mechanics remain unenforced by design.

Explicitly unsupported after this milestone (documented, not accidental — superseded in part by the 2026-07-19 and 2026-10-16 amendments below): reaction triggers beyond hit-by-attack/half-damage (opportunity attacks, Parry-style AC responses, damage-taken triggers), triggered features (Relentless Endurance, Dark One's Blessing, Halfling Lucky, Sneak Attack eligibility, since shipped as an extra on the hit), concentration and target-scoped effects (Hex), movement/range/reach/line-of-sight legality, rolled grapple escapes (the escape DC displays; ending the effect is manual), incapacitated-ends-grapple (only 0 HP releases), player-invoked `action.resolve`, per-encounter monster death policies, ruleset (2014/2024) declarations and import compatibility levels, structured recharge/legendary actions, and beam-count-by-level expressions (static counts in definitions). Non-turn-scoped always-on attack advantage (e.g. Invisibility) needs a new modifier flag — do not reuse `attack-advantage` for it. What remains is tracked on the roadmap issue, not here.

## Amendment — 2026-07-18 (second slice, same PR)

9. **Reaction prompts.** Declared reactions (`reaction: {trigger: "hit-by-attack", response: "half-damage"}` — Uncanny Dodge) become first-class pending prompts on the pendingSaves template: a qualifying hit (structured attack, damage > 0, reactor's reaction free, reactor not incapacitated, mode not freeform) parks its rolled typed damage on `combat.pendingReactions` _instead of_ the runner's apply button. `reaction.answer` (GM anyone; a player their claimed character) applies the damage either halved (the total, rounded down once; use — spends the reaction) or in full (decline); the halving happens before defenses, so resistance still applies on top. `reaction.dismiss` (GM) drops a prompt without applying — the escape hatch for damage entered by hand. Prompts persist across turn changes until answered so parked damage is never silently lost; player projections carry only the player's own prompts, source ids stripped and hidden sources masked.
10. **Incapacitation gates the economy.** An actor with Incapacitated (or a condition that includes it: Paralyzed, Petrified, Stunned, Unconscious) violates `condition.incapacitated` for any action, bonus action, or reaction — handled by the same strict/assisted/override ladder as every rule.
11. **Available-actions read.** `GET /game/actors/{actorId}/available-actions` (and the `actor:available-actions` socket read) reports per-action availability computed by the _shared_ `evaluateActionEconomy` — the exact evaluation strict resolution enforces, so the report can never drift from enforcement. Rows carry machine-readable violations, uses remaining, and open-instance counts. GM-grade any combatant; a player only their claimed character (availability names stat-block internals). Target-specific rules need a target and are not pre-checked.
12. **Archive v3.** Encounter archives additively gain `postEncounterState` — the state after `encounter.end` ran (combat cleared, end-of-fight effect sweeps and their on-end grants landed). `finalState` (the last live picture) is unchanged; the fight's true aftermath was previously unrecorded.

## Amendment — 2026-07-19 (SRD gap closure, tiers A–D, same PR)

A full cross-audit of the SRD 5.2.1 combat chapter, rules-glossary actions, and conditions appendix against the engine closed the verified gaps in four tiers. Everything below rides the existing machinery — the rules ladder (strict/assisted/freeform with audited overrides), explainable advantage/disadvantage sources, the additive-with-defaults state rules, and the projection allowlists. Where a rule needs a subsystem the app deliberately lacks (vision/light, terrain, hands/inventory), the GM supplies the judgment call as a command input and the server applies the math.

13. **Condition completeness (Tier A).** Every SRD condition now has its mechanical teeth: frightened → attack disadvantage (applied whenever active — line-of-sight is GM adjudication, a documented simplification); invisible → own-attack advantage / incoming disadvantage; grappled attacker → disadvantage against everyone but the grappler (source-linked effect names the grappler; a hand-set condition falls back to "grappler unknown" disadvantage against all); paralyzed joins unconscious in the within-5-ft auto-crit; paralyzed/petrified/stunned/unconscious auto-fail Strength and Dexterity saves (the manual-total path deliberately bypasses — the GM escape hatch); restrained → Dex-save disadvantage; exhaustion applies −2 × level to attacks and saves, −5 ft × level to Speed, and level 6 is death; petrified adds resist-all at damage time and immunity to the Poisoned condition (SRD 5.2.1; the 2014 poison damage immunity is gone); `conditionImmunities` (GM-only knowledge, stripped from player projections) skip-with-narration; charmed blocks targeting the linked charmer (`condition.charmed-charmer`).
14. **Builtin generic actions (Tier B).** The eleven 2024 generic actions plus Unarmed Strike variants ship as a code-side catalog (`builtin-actions.ts`, frozen ids — a replay contract) available to every combatant, definition or none; a stat block action with the same id shadows the builtin. Dodge/Disengage/Dash/Help/Ready grant tagged effects with typed modifiers (`voidWhileIncapacitated` — Dodge lapses per the SRD); Influence/Search/Study consume the action and roll the ability check; Magic/Utilize consume and narrate. Hide rolls Dex (Stealth) vs DC 15 → an Invisible-linked Hiding effect that any attack reveals (eligibility — cover, obscurement, sight lines — is GM adjudication). Help targets one ally with attack advantage until the helper's next turn (the SRD's next-attack-only scope widens to the round; documented). Unarmed Strike materializes Str + PB / flat 1 + Str; Unarmed Grapple/Shove force the target's better Str/Dex save vs 8 + Str + PB with a one-size cap, grapples landing as escapable source-linked effects (escape DC = the same formula); Escape Grapple rolls best of Athletics/Acrobatics vs the DC; an incapacitated grappler releases its holds. Ready parks a free-text trigger; the reactor's next off-turn resolve spends the reaction and releases it.
15. **Movement and opportunity attacks (Tier C).** `Actor.speedFeet` (optional — unknown speed skips checks, the unmeasurable pattern) seeds from definitions with a GM `actor.set-speed` command; `turn.movementUsedFeet` accumulates on-turn willing moves against the creature's live Speed (`max(0, max(0, speed − 5 × exhaustion) + the `speed` modifiers its effects carry)` — the reduction floors at 0 where it applies, so a bonus is never eaten by an exhaustion debt, and effects sharing a `stackKey` contribute their single most potent value rather than summing, per the SRD's “Combining Game Effects”) PLUS the extra-movement grants taken this turn: Dash records `movementGrantFeet` on its effect when the action is taken (“equal to your Speed after modifiers”, fixed then) instead of doubling the live Speed on every read, so a Slow landing mid-turn cannot re-price feet already granted; a `dashing` effect stored before that field degrades to the old doubling. 0 while grappled/restrained/unconscious/paralyzed/petrified (“your Speed is 0 and can't increase” refuses the grant too; Stunned no longer zeroes Speed in SRD 5.2.1); overruns are `movement.exceeds-speed` violations with a GM-only override, and standing from Prone charges half Speed (`movement.stand-up-cost`). Leaving an able enemy's melee reach without Disengaging opens a `leaves-reach` reaction prompt (side heuristic: player-characters vs monsters, npcs excluded; the move completes first — arrival timing is a documented approximation); answering resolves a real melee attack (declared action, first melee, or the builtin Unarmed Strike) against the mover off-turn and auto-applies its damage — which the mover's own Uncanny Dodge can intercept. A hidden mover prompts no one (viewer safety); the GM resolves that retreat manually. Range/reach validate at resolve when measurable: melee beyond reach (`range.out-of-reach`), ranged beyond maximum (`range.out-of-range`), long range and ranged-in-close-combat disadvantage sources (the enemy within 5 feet is a living, able creature on the other side: player characters are the party, any other creature takes its side from its stat block's disposition); the ETL now splits "80/320" into normal/maximum bands.
16. **Cover, concentration, surprise, rests (Tier D).** Cover is GM-selected (no line-of-sight engine), per resolve or as a standing marker the GM puts on a creature from its row tools (an effect tagged `cover-half`, `cover-three-quarters` or `cover-total`), which every attack and Dexterity save against it then reads, a player's included: half +2 / three-quarters +5 to AC and Dex saves, total an overridable `cover.total` block for a single target (a marked creature among an area's targets is a GM note). Concentration: `concentration`-flagged effects are one-at-a-time per source, damage prompts a CON save at DC `min(30, max(10, ⌊damage/2⌋))` whose committed failure ends the sustained effects, and incapacitation or 0 HP breaks concentration immediately. Initiative is one roll for every path (the fight's start, a player's own roll, a mid-fight joiner): Surprise and any Incapacitated condition give Disadvantage, Invisible and `roll-mode` riders give Advantage, they cancel per the 2024 rules, and Exhaustion comes off the total. A player can't choose the mode. A score change mid-round never moves anyone across the current turn; the next round sorts fully. Short rests re-arm `per: "short-rest"` pools (and, since 2026-10-16, Pact Magic slots) only — hit dice are unmodeled, so no HP change (the GM heals manually).
17. **Environment and mercy rules (Tier D niche).** A GM `encounter.set-environment` toggle marks the fight underwater: non-spell melee attacks have disadvantage unless the attacker has a Swim Speed or the weapon deals piercing damage (the SRD's weapon list generalized to its shared damage type), non-spell ranged attacks have disadvantage within normal range and auto-miss beyond it (`range.underwater`), fire resistance for every combatant. `actor.apply-damage` accepts `nonlethal`: a drop to 0 knocks out — at 1 HP and Unconscious (SRD 5.2.1) until it regains hit points, no death saves, no defeat; a named source action that is not a melee attack is refused. The dice panel gains a falling-damage helper (`min(⌊feet/10⌋, 20)d6` rolled server-side, Prone reminder).

Still explicitly unsupported after this amendment (deliberate): mounted combat, jumping, burning/suffocation timers, breaking objects, readying a spell (concentration while held), and vision/light/line-of-sight and auto-derived cover. Underwater speed halving is folded into the GM's speed adjustments rather than automated. Four items this list once held have since shipped in later amendments: hit dice, difficult terrain, two-weapon fighting with the Light property, and weapon mastery.

## Amendment — 2026-07-19 (Foundry-dnd5e adoption pack: recharge, legendary resources, hit dice; same PR)

A design study of Foundry's dnd5e system (MIT code; studied, never copied) identified three monster/rest mechanics the engine lacked. All three ride the existing machinery — `actionUses` pools, the turn-start hook, the save answer flow, the additive-state and new-command checklists.

18. **Recharge abilities.** `ActionSchema.uses.per` gains `"recharge"` with a 2–6 d6 threshold (a superRefine pins the pairing). The ETL emits structured pools instead of prose-only names: `RECHARGE_ON_ROLL` → `{limit 1, per recharge}`; `RECHARGE` **with a numeric param** is also a die-range recharge (an upstream data quirk — basilisk/medusa Petrifying Gaze, blink dog Teleport and ten others print "Recharge X–6" in the SRD; the param carries the threshold), leaving one true rest-recharge (cloaker Phantasms) mapped to `short-rest`; `N/Day` maps to `long-rest` (the app has no calendar — a day is a long rest, a documented simplification shared with Legendary Resistance). 86 recharge and 28 rest-scoped pools across the 330-monster bundle; double-printed "(Recharge …)" name suffixes are fixed. At the start of the owner's turn `nextInitiativeTurn` rolls the d6 per spent pool (deps threaded from `initiative.next` and `turn.end` with the audited RNG — the deterministic test queue drives it) and narrates the die either way, to the GM alone for a monster (its resources are GM knowledge; the table sees the breath when it is used); `previousInitiativeTurn` deliberately never rolls (GM correction; the Time Machine is the undo). Encounter start and both rests re-arm pools.
19. **Legendary actions and Legendary Resistance.** `ActionSchema` gains `legendary {cost}` (all 82 SRD rows cost 1) and definitions/actors gain `legendary {actionsPerRound, resistancesPerDay}` (every SRD legendary creature prints 3 per round — the "(4 in Lair)" bump stays prose; 32 creatures carry resistance at the printed non-lair N). The per-round pool is `combat.legendaryUsed` (actorId → spent), refreshed exactly like `reactionsUsed` — the incoming actor's entry clears at its own turn start, in both turn directions — carried through scene park/resume, restored by timeline rewinds, and **stripped from player projections** (monster resources are GM knowledge, the `actionUses` rationale). `evaluateActionEconomy` blocks own-turn use (`legendary.own-turn` — legendary actions happen on other creatures' turns) and over-pool spends (`legendary.no-actions-remaining`) through the rules ladder; a GM-only `turn.use-legendary` sets the pool by hand (the spend path for prose-only legendary actions). Legendary Resistance rides `actionUses["legendary-resistance"]`: `save.answer` accepts a GM-only commit flag that forces the success outcome after a previewed failure — the success consequences (half damage where the save halves) still apply, a natural success spends nothing, and a long rest re-arms the daily pool. The tracker offers off-turn legendary creatures as one-tap console switches (⭐ strip) and failed-save previews grow a "Legendary Resistance (N left)" commit.
20. **Hit Point Dice.** `Actor.hitDice {die, maximum, remaining}` (nullable — absent means unmodeled and rests behave exactly as before) seeds from the definition's hit-point formula at roster time. The new `actor.spend-hit-dice` command (GM any actor; players their claimed character) rolls the faces **before** the store executes (the `dice.roll` idempotency pattern), heals `max(1, face + Con modifier)` per die (SRD minimum) through `healActor`'s single-sourced rules, decrements the pool, and lands the dice in the shared roll history (hidden actors GM-only); it is rejected mid-encounter, matching the rest guard. A long rest restores all spent dice (SRD 5.2.1 "Regain All HP"); short rests still change no HP by themselves — spending is the explicit act. The pool reaches only the owning player and is excluded from the timeline's restorable slice (an out-of-combat resource). The roster grows the previously missing rest UI: GM Short/Long rest buttons and a hit-dice stepper per card, mirrored on the player's own card.

## Amendment — 2026-10-16 (difficult terrain and the movement preview)

21. **Difficult terrain.** The GM paints it per scene on a calibrated grid (`terrain.paint` / `terrain.reset`), stored as disjoint cell-snapped rects (`combat.terrain.difficult`). A token move is now charged along the cheapest 8-way grid path (`movementPath` in `@vtt/rules-5e`) instead of the endpoint-to-endpoint count: a step costs one cell, or two when any cell of the mover's footprint lands in difficult terrain or in a creature's space that is difficult for it (an enemy that isn't Tiny, per the SRD; player characters and monsters are each other's enemies, NPCs are left to the GM). Hidden creatures never count, so a player's preview can't disagree with the charge. The extra cost doesn't stack. A path can't leave the map to walk round something. Opportunity attacks still compare the move's two endpoints. Painting terrain is scene dressing: it neither dirties the combat timeline nor rewinds with it. Players and the table screen receive only the terrain the fog reveals; terrain under the fog is still charged.
22. **Movement preview.** Dragging a token on a calibrated grid draws the path and its cost from the same function, and the `actor:movement` read reports the budget the move is charged against (counted or not, effective Speed with Dash, feet spent, strict or assisted), so the label reads "35 ft (5 ft difficult) · 5 ft left" or "... too far". The old client-only "Show distance while moving" and "Add 5 ft per occupied square" switches are gone; the preview always shows during a drag, and occupied squares are the rule above.

## Amendment — 2026-10-16 (reaction triggers: AC bonuses and striking back)

23. **AC reactions.** `reaction` widens from one shape to four (`ActionReactionSchema`): `half-damage` (Uncanny Dodge) as before, `ac-bonus` (`amount`, optional `melee`, optional `untilNextTurn`), and two `damaged-by-creature` responses below. A committed attack that would hit a target holding an affordable `ac-bonus` reaction stops at its roll when the bonus would turn it into a miss: the attack's economy is spent, nothing past the roll happens, and an `attack-would-hit` prompt holds the attack (`parkedAttack`, GM-only: the action, the kept die or typed total, cover, slot, distance and who rolled it). Answering finishes it with the same die (`economyPaid` skips the economy the second time): "use" first spends the reactor's reaction and the action's own cost (Shield's slot, Protective Magic's use), then adds the bonus against this attack (Parry) or grants an effect carrying `armorClassBonus` until the reactor's next turn (Shield), read through `armorClassInPlay` by the attack roll and the sheets. A hit's damage then applies like an opportunity attack's, so the GM's apply button and manual damage entry don't apply to it. A critical hit is never offered (it lands whatever the AC). Parry, Riposte and Whirlwind of Sand are read from stat-block prose (`acReactionOfProse`, melee when the trigger names a melee attack); Protective Magic, the Shield spell and the builder's spell actions declare it.
24. **Striking back.** `damaged-by-creature` with `strike-back` resolves the declared action against the creature that dealt the damage (Hellish Rebuke's save, Storm's Thunder's damage); with `melee-attack` it makes one melee attack, picked like an opportunity attack's and spending the reaction even on the reactor's own turn (Retaliation, now modeled). The prompt opens wherever damage applies with a known source creature (`DamageInput.sourceActorId`: the GM's apply, a player's direct or confirmed hit, a save's outcome, a reaction's own damage), only while the source is public, alive and in the fight, the reactor could take the action, and the map doesn't show the source beyond `rangeFeet` (an unmeasurable distance is the table's call). A second hit while one waits opens no second prompt. Counterspell, Feather Fall, Stone's Endurance and reactions protecting another creature stay prose.

## Amendment — 2026-10-16 (the last three weapon masteries, and the Light property)

25. **Light and Nick.** Each equipped Light weapon, once two are in hand (another weapon, or a pair of the same), gets an engine-minted extra attack (`extraAttack: {kind: "light"}`, id `item-<id>-light`): usable after an attack with a different Light weapon in the Attack action this turn (recorded in `turn.extraAttacks`, never projected), once per turn across all of them, its damage without a positive ability modifier unless the bearer has Two-Weapon Fighting. It costs the Bonus Action, or nothing when the weapon making it has Nick (part of the Attack action). It carries the weapon's own mastery. The 2026-07-19 line that kept two-weapon fighting and the Light property unsupported, and weapon mastery with them, is superseded.
26. **Cleave.** A melee hit with a Cleave weapon opens its `-cleave` swing, offered on the result card: once per turn, at another creature within 5 feet of the first (checked when the map can measure) and within reach, spending no action, its damage without a positive ability modifier.
27. **Vex.** A hit that deals damage (after the target's defences) lays a "Vexed by" marker on the target, linked to the attacker; the attacker's next attack roll against it has Advantage and spends the marker, hit or miss. It lasts until the start of the attacker's turn after next, a turn of opportunity attacks longer than the SRD's "end of your next turn", since effects expire only at turn starts. Slow likewise needs a hit that deals damage, and Sap's Disadvantage is spent by the sapped creature's next attack roll.
28. **Graze lands.** A miss carrying Graze damage now owes it like a hit: the GM's apply button, a player's proposal or direct damage, and an opportunity attack or a finished parked attack all apply it. It used to show on the card and go nowhere.

## Amendment — 2026-10-16 (extras on a hit, damage with no attack roll, printed monster damage)

29. **Extras ride the hit.** Sneak Attack, Divine Smite, Searing Smite, Shining Smite, Divine Strike, Primal Strike and a monster's printed charge are offered on an attack's preview (`hitOffers`) and chosen with its confirm (`hitOptions`, with a damage type or a slot where the extra takes one). Their dice join the hit's damage, so a crit doubles them and the target's defences meet them as one hit; their costs (a per-turn use, a slot, the Bonus Action) are spent with the hit, and a miss spends nothing. The server checks each: the weapon (Finesse or Ranged for Sneak Attack, a Melee weapon or an Unarmed Strike for a smite, any weapon for the strikes), the turn ("once on each of your turns"), and Sneak Attack's Advantage, or an able ally within 5 feet of the target and no Disadvantage. Where the map can't measure, the offer says so and the attacker vouches for it. Sneak Attack takes the weapon's damage type; Divine Smite adds 1d8 against a Fiend or an Undead; Shining Smite marks the target with an effect that gives attacks against it Advantage; Searing Smite leaves an effect that burns again at the start of each of the target's turns (item 33). Taken alone, any of them is the overridable `attack.rides-a-hit` block; an extra the hit can't carry is `attack.hit-option-unqualified`. The riders are a code-side table keyed by action and spell id, so sheets built earlier get them too. A parked attack (Parry, Shield) carries its chosen extras to the replay.
30. **Damage with no attack roll and no save** (Magic Missile) is owed to each target like a hit's (`damageTargets`, each with its own typed parts): the GM's card has an Apply per target, and a player's lands as a proposal or directly, per the table's player-damage mode.
31. **Monster damage as printed.** The ETL reads each attack's damage from its printed hit clause (the open5e rows dropped extra damage on 91 attacks and had wrong dice on 7), fixed amounts ("1 Piercing damage") included, and its conditional damage as `conditionalDamage`: Advantage, its own or the target's Bloodied, the target Grappled by it, applied by the engine; and a charge, which the engine can't see, offered on the hit. A save action deals at once only what the first sentence of its failure prints; damage at the start of later turns (swallow, engulf) is the save's `ongoingDamage` (item 33), and what the engine can't deal (an infernal wound's lost hit points) and failures that turn on the target's Hit Points become the action's `reminder`, shown to the GM when it resolves.

## Amendment — 2026-10-16 (conditions, effects, durations and Concentration)

32. **Every imposed condition has a source and an end.** A failed save's conditions land as one source-linked effect (`failureEffectFor`, applied by `applyFailureEffect`), so Charmed knows its charmer and Grappled its grappler. Prone (ended by standing) and Exhaustion (cumulative: each time it is received adds a level, from any path) stay bare. The save block carries how the conditions end, read from the SRD text at build time (`save-outcomes.ts`) or authored on class features and items: `failureDuration` ("for 1 minute", "until the start of the X's next turn", "until the end of its next turn" (the target's), "until the end of your/the X's next turn" (the source's)), `repeatSave` ("repeats the save at the end of each of its turns"), `escapeDc` and `rangeFeet` for a grapple (its "Restrained until the grapple ends" companions ride the same effect), `endsOnDamage`, `speedZero`, "while X, also Y" companions (Hypnotic Pattern's Incapacitated, a chuul's Paralyzed), `failsAtHitPoints` (Power Word Stun: no save at the cast), and `ongoingDamage` ("takes 21 (6d6) Acid damage at the start of each of the behir's turns": the dice, and whether it is the target's turns or the source's). On-hit riders carry the same `duration` and grapple companions; one the hit's sentence gives with no end lasts until ended (an otyugh's Poisoned, which a save after a Long Rest ends). Effects gain the matching durations `until-bearer-turn-end` / `until-source-turn-end` (with `skipsCurrentTurn` when they begin on that creature's own turn) and the fields `repeatSave`, `endsOnDamage`, `speedZero`, `castId`, `rangeFeet` and `ongoingDamage`.
33. **The ends and starts of turns are steps.** `nextInitiativeTurn` runs `endOfTurn` (`turn-boundaries.ts`) for the outgoing combatant before the next begins: turn-end durations it owns lapse, then each repeating effect it bears opens its save as a pending save whose success ends the effect (`repeatOf`). Once the incoming combatant's durations tick, `startOfTurn` deals each effect's `ongoingDamage` that falls on that turn, the bearer's own or the source's (a source at 0 HP deals none): the dice roll on the server and the damage meets the bearer's defences, temporary hit points, Concentration and death saves like any other. An effect whose damage is followed by a save (`saveToEnd`, Searing Smite) opens it then, a success ending the effect. The dice stay with the GM: players see the effect and the damage when it lands. Damage printed for the end of a turn, and hit point loss, stay with the GM. The GM's backward step runs none of this.
34. **Casting a Concentration spell starts Concentration.** The resolve step `startConcentration` gives the caster "Concentrating on X" (`concentrating` tag, `concentration`, the spell's duration up to 100 rounds, else until ended) and a `castId` every failed save of that cast shares; starting another ends the caster's others (one at a time), and ending the caster's effect ends the whole cast. A Concentration smite chosen on a hit (Shining Smite) starts it the same way, its mark on the target sharing the `castId`. Damage asks for the Constitution save in or out of a fight; Incapacitation from any path (`conditionGained`, shared by every condition writer), 0 HP, a GM HP edit to 0, Exhaustion 6 and a long rest's sleep end it. A save answered after the Concentration broke imposes nothing. A GM-added concentration effect may name its caster as `sourceActorId`.
35. **Implied conditions and their ends.** Unconscious brings Prone (which stays after it); Petrified drops and refuses Poisoned; Dodge lapses at Speed 0 too; a knocked-out creature wakes when it regains hit points; an effect ending leaves a condition also set on its own (`standalone`).
36. **Who may end what.** The GM ends anything. A player adds conditions to their character and takes off only what they added (`selfApplied`); a condition or effect imposed on them is a `condition.imposed` block (economy family) they can ask the GM about (`effect.end` is now askable), and standing from Prone off their own turn is `movement.stand-up-off-turn`. A player may end any effect their character is the source of, on any creature (a released grapple, a dropped Concentration); the player projection marks those `yours` and strips `castId`.
37. **Incapacitation reaches every activation.** Legendary actions and `activation: "other"` feature activations (Sneak Attack, Reckless Attack, Action Surge) are refused while Incapacitated or at 0 HP through `condition.incapacitated` / `condition.down`, except the few that answer a roll or an event (Indomitable, Relentless Endurance). Rage lasts until the end of the Barbarian's next turn, extended by an attack roll or forced save against another creature or by re-declaring it as a Bonus Action (no use spent), ends on Incapacitation or in Heavy armor, ends the Barbarian's Concentration and refuses spells (`condition.raging`). Danger Sense and the Paladin auras are gated on not being Incapacitated.
38. **Fight's end and rests.** Encounter end and a long rest end only effects measured in turns or rounds (and the rester's Concentration); "until ended" effects (a curse, a grapple still held, an hour-long Concentration) outlast them. Opportunity-attack prompts need sight: none for an Invisible mover or a Blinded reactor unless its Blindsight (or, for Invisible, Truesight) reaches. A grapple ends when a move takes the two farther apart than its range. Each turn opens with a reminder line listing the incoming combatant's conditions and effects, with source and time left.

Still open after this amendment: Rage's 10-minute cap and Persistent Rage's longer form, the second stage of two-stage saves (a basilisk's Petrified, Sleep's Unconscious), escape checks for spell restraints (Entangle, Web), Fast Movement and Roving in Heavy armor (their Speed is baked into the sheet), and ending a swallowed creature's conditions when the swallower dies.

## Amendment — 2026-10-16 (spellcasting: slots, casts and what spells leave behind)

39. **Spell slots.** A leveled spell's cast spends one slot when it starts, at the level asked (`slotLevel`; absent, the lowest at or above the spell's level with one left). Pact Magic is its own pool (`pactSlots`, every slot at the Warlock's slot level), refilled by a Short or a Long Rest and shown as its own pips; a multiclass caster spends either pool on either class's spells, a pact slot first at a level both pools have. The `slots` family checks one slot per turn (`slots.one-per-turn`, cantrips and slot-free casts aside), none below the spell's level, none from an empty pool and only a prepared spell (`slots.not-prepared`; the Long Rest prepare step is ADR-0021's), and advises by default; the GM's "Don't police spell slots or prepared spells" makes it freeform on the sheet and outside a fight too. A prepared ritual spell also casts as a Ritual without a slot (`spell-<id>-ritual`). A casting time of a minute or more takes the Magic action on each of its turns, is refused while Incapacitated, and spends its slot when it starts; the cast reminds the GM.
40. **Casts.** A spell with several attack rolls (Scorching Ray, Eldritch Blast's beams) opens its own component keyed by the action (item 3's generic `attack` pool is the Attack action's alone), so a swing never comes out of a spell's rays nor a ray out of Extra Attack; every ray rolls at the cast's slot, and a higher slot adds rays and Magic Missile's darts. Darts (`darts`) roll one by one and strike the targets listed in order, a target named twice taking two, so each target is owed only its own darts (`damageTargets`, item 30). A spell attack takes its range and its melee or ranged kind from the spell (a spell attack is never a weapon's: `melee-weapon` and `ranged-weapon` are a `weapon` attack made in melee or at range); a save or healing spell checks its range and how many creatures it targets at this slot (`range.out-of-range`, `target.too-many`); Sacred Flame's save ignores cover (`ignoresCover`); the caster picks Chromatic Orb's damage type (`damageTypes`). A save made later, or never by the target (Spirit Guardians, Haste), prompts none at the cast; what a spell lets its caster do later is its own action (`spell-<id>-then-<name>`), which the cast reminds the GM of. An area catches its caster when the template covers it (an Emanation, Cone or Line from the caster never does), and a healing area heals the creatures the caster picks, up to its count.
41. **What spells leave behind.** A spell's cast model (`SpellReference.effect`) carries a `grant` for the creatures the cast targets (`target: "targets"`, Bless) or the one its attack hits (`onHit`, Guiding Bolt's light), with `armorClassBonus` while it lasts (Shield of Faith, Haste; read by `armorClassInPlay`), and a save's `failureEffect` (Bane, Faerie Fire); the character build copies them onto the spell's action (`ActionGrantSchema`, `save.failureEffect`), and an older sheet's spell action gets them when it resolves. `attack-bonus` and `save-bonus` riders may carry signed `dice` ("1d4", "-1d4"): a save rolls them in, and an attack rolls them once it is made for real, shows them still to roll in a preview, and keeps them through a parked attack. A `by-effect-source` filter lets an effect's riders fire only for the creature that put it on the bearer, so Hunter's Mark and Hex add their 1d6 to their caster's hits on that creature alone. One spell's effects on a creature share a `stackKey` (`spell:<id>`) and count once, AC included. Guiding Bolt's light ends with the next attack roll against the creature, whoever makes it (`until-attacked`); Faerie Fire's outline (`outlined`) takes away the Invisible condition's benefit. Mage Armor and Haste measure the creature when they land (13 + Dexterity, nothing in armor; Speed doubled). The effects carry the spell's own duration, and a Concentration spell's share its `castId` (item 34, the grant running after `startConcentration`, the failure effect through `failureEffectFor`), so they end with the caster's Concentration. The line above listing target-scoped effects (Hex) as unsupported is superseded.

## Amendment — 2026-10-16 (action economy and movement)

42. **Turns.** An action or a Bonus Action off the creature's own turn is the `economy.not-your-turn` block on every path (`action.resolve` from the map's targeting as well as `action.use`), overridable by the GM and askable by a player; the message names the current creature only when the table can see it. A Readied creature's response off its turn is its Reaction: it spends the Reaction, and with none left it is the `economy.reaction-used` block rather than a free release. A player's Ready trigger reaches the effect's name, as the GM's does.

## Mobile, security, and visibility impact

All validation, rolls, and effect lifecycle run server-side; phones and desktops see identical outcomes. Blocked rows stay tappable in the GM UI — the server rejection opens the one-tap override dialog, so the client never gates (server authority, CLAUDE.md rule 2). New projection fields are explicit allowlists: effects reach players without source actor/action ids (hidden sources masked as "A hidden threat"), a hidden combatant's turn instance and per-turn uses project as idle, limited-use spending travels only to the owning player, and the public viewer projection is unchanged.

## Migration / reversibility

All state additions are additive-with-defaults on schemaVersion 1: existing campaigns, turn snapshots, and archives parse unchanged, and old journals replay under `freeform` mode. The bundle regeneration is deterministic and reviewed in git. Reverting enforcement is a one-line default change (`rulesMode` to `freeform`) with no state migration; removing the mechanics fields would require a content-schema review per ADR-007.
