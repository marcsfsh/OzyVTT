# ADR-020: Combat rules engine (validated action resolution, effects, typed damage, and the dying state)

## Status

Accepted on 2026-07-18. Amended the same day (second slice, same PR): reaction
prompts, incapacitation gating, the available-actions read, and archive v3 (see
"Amendment" below).

## Context and decision drivers

A forensic comparison of two archived runs of the same encounter (a manual GM run and a rules-aware recreation driven through the integration API) showed that the engine recorded mechanics but did not own them: the manual run performed two Frenzy attacks plus a Greataxe attack in one round-one turn with no Rage active, resolved Extra Attack as unrelated single rolls, applied crocodile damage to a raging barbarian with no resistance, never created the Bite grapple as state, and used seven manual heals (five of exactly 1 HP) as a stand-in for a dying state. None of this was blocked, warned about, or guided. The automated recreation proved the low-level API could emulate the rules, at a cost of 120 commands for a three-round fight, with the rules in an external script and out of the server.

The owner's direction for this milestone: combat should "just work": the legal action is the easiest path, unavailable actions are clearly explained, and the GM keeps an explicit, audited override for homebrew and intentional exceptions. This supersedes the earlier blanket posture that action economy is "tracked, never enforced" (ADR-008's reference level; BUILD_PLAN §13.4 "do not hard-block extra actions"), which these runs showed delegates too much rules bookkeeping to the GM's memory. Design precedent for the typed-mechanics vocabulary was validated against MIT-licensed sibling projects (notably cbgfx/beholden's typed-effects compendium schema), for patterns only, with no code or data reuse.

## Considered options

- Keep reference-level tracking and improve display only: preserves the old posture but cannot prevent any of the observed error classes.
- A high-level "execute action" API that atomically rolls every attack, applies damage, and resolves prompts in one transaction (the gap-analysis report's original proposal): maximally guided, but reshapes the one-command-one-roll journal/archive contract, breaks replay of existing archives, and removes the GM's between-rolls target choice.
- Validated resolution over the existing command surface (chosen): `action.resolve` stays one roll burst per command, but validates against engine-owned state before rolling, with a per-encounter enforcement mode and an audited override.

## Decision

The server owns combat rules state and validates structured action resolution against it (extending ADR-008, whose representation rules are unchanged: declarative vocabulary, bounded dice grammar, no imported executable code).

1. **Structured mechanics vocabulary** (additive-optional on `ActorDefinition` schemaVersion 1, per ADR-007): `attack.count` (Extra Attack, beams), `attack.criticalBonusDice` (Savage Attacks), `multiattack` composition, `onHit` condition riders with escape DCs and size caps, `targetRules`, `grants` (self effects like Rage/Reckless with typed modifiers, durations, and on-end grants), `requiresEffectTag`, `uses` (per turn/encounter/long-rest with shared pools), and typed defense lists (`damageResistances`/`damageImmunities`/`damageVulnerabilities`/`conditionImmunities`). The SRD ETL emits these from confident statblock patterns only (126 of 178 Multiattacks, 47 on-hit riders, 146 monsters with typed defenses); everything else stays inert prose.
2. **Rules modes with an audited override.** Each encounter carries `rulesMode`: `strict` (the default: invalid structured resolutions are rejected with machine-readable `blocked {rule, message, overridable}` details), `assisted` (allowed, conflicts logged as warnings), `freeform` (no checks). Any rejection can be bypassed by resending with `override: {reason}`, which is prominently recorded in the combat log (kind `override`) and the journal. An actor whose stat block has a prose-only Multiattack degrades action-slot violations to warnings even in strict mode, since the engine never polices rules it cannot see. Manual commands (`turn.use`, amount-only damage, `actor.set-condition`, `actor.set-hp`) remain free escape hatches for the GM (a player's `actor.set-condition` is policed since the 2026-10-16 conditions amendment, and a player's giving back a spent slot since the action economy amendment); un-marking the action slot also clears the open compound-action instance.
3. **Action instances.** Resolving an action-activation action with a free action slot consumes the slot once and opens an instance of remaining components: a generic `attack` pool for `attack.count` (so Extra Attack may legally mix weapons), actionId-keyed components for `multiattack` (Bite + Tail). Further resolves consume components; exhausted instances reject with "no attacks remaining". One command still equals one roll burst, so journal/archive semantics and sequential target choice hold.
4. **Persistent effects.** `Actor.effects` holds engine-owned `EffectInstance`s (name, tags, source links, duration, typed modifiers, linked conditions, escape DC, on-end grants, `endsWithTag` cascades). The engine ends them: durations expire at the source's turn start, a source at 0 HP releases what it sustains (grapples, its own Rage), `endsWithTag` cascades (a marker effect ends with the effect it depends on, firing its on-end grants exactly once), encounter end sweeps the fight's combatants (on-end grants fire, a documented simplification; since the 2026-10-16 conditions amendment only effects measured in turns or rounds), and grants from the same source actor + action refresh and never stack. Sweeps are scoped to the current initiative so parked scenes keep their effects. On-hit riders auto-apply conditions at resolve time, the same owner-approved carve-out class as save auto-apply.
5. **Typed damage at apply time.** `actor.apply-damage` accepts optional typed `parts`; the server applies flat reductions → immunity → resistance-halving → vulnerability (resistance and vulnerability on one type both apply, halving first, per the SRD 5.2.1 Order of Application) from definition defenses plus active effects, then temp HP, and returns/logs the per-part breakdown ("17 bludgeoning → 8, resistance: Rage"), so no adjustment is silent. The bare `amount` stays exact for manual corrections. Pending saves carry typed parts and halve the total once on success (rounded down, spread back over the types).
6. **Advantage aggregation with explanations.** Attack resolution aggregates advantage/disadvantage sources (effect modifiers: `attack-advantage` is evaluated only on the bearer's own turn, Reckless semantics; incoming-attack-advantage on the target; prone with the 2024 distance rule via authoritative token distance; restrained/poisoned/blinded/stunned/paralyzed/petrified/unconscious; unconscious + adjacent upgrades hits to crits), cancels per 5e, rolls `2d20kh1/kl1`, and reports every contributing source. An explicit `rollMode` wins only from the GM, named as the GM's choice; a player's is ignored (ADR-0012).
7. **The dying state.** Damage dropping a player character to 0 applies Unconscious + Prone and initializes death saves (instant death on overflow ≥ max HP); damage while dying adds failures (two on a crit; stability breaks and counters restart from zero per the SRD reset rule); `death-save.roll` runs the d20 pipeline (20 → 1 HP + conscious; 1 → two failures; a total of 10+ after Exhaustion, save bonuses, Bless's d4 and an ally Paladin's Aura of Protection succeeds; Advantage and Disadvantage come from riders on every save; three successes → stable with counters reset; three failures → dead), a previewed die is held until confirmed (ADR-0012), and in a fight a player commits one per turn, on the dying character's own turn; healing or set-hp above 0 clears the dying state (Prone stays). Non-player combatants at 0 are "defeated" (effects they sustain end; no death saves). All five HP entry points share this machine.
8. **Command surface.** New commands `effect.add`, `effect.end`, `death-save.roll`, `encounter.set-rules-mode`, `actor.rest` (Long Rest: effects end first, HP/uses/dying reset, Exhaustion −1) ride the shared operations layer, both transports, the OpenAPI contract, and the archive journal like every other command (ADR-016 no-fork). Timeline restores and the dirty comparator cover effects, death saves, spent uses, spell and Pact slots, and Hit Dice; player projections strip effect source ids, mask hidden source names, and expose limited-use spending only for the claimed character.

## Consequences and tradeoffs

The published `turn.use` semantics changed from "(tracked, never enforced)" to "manual toggle; structured resolution validates per rules mode". Integrations replaying old journals (or scripting freely) should set `freeform` mode first, and a mid-flight encounter upgraded under this release parses to `strict` and may see first rejections until the GM overrides or switches modes. Slot enforcement applies on the acting combatant's own turn; off it, an action or Bonus Action is the `economy.not-your-turn` block (since the 2026-10-16 action economy amendment), and reactions, legendary actions and a readied response are the off-turn activations. Prose-only mechanics remain unenforced by design.

Explicitly unsupported after this milestone (documented on purpose, and superseded in part by the 2026-07-19 and 2026-10-16 amendments below): reaction triggers beyond hit-by-attack/half-damage (opportunity attacks, Parry-style AC responses, damage-taken triggers), triggered features (Relentless Endurance, Dark One's Blessing, Halfling Lucky, Sneak Attack eligibility, since shipped as an extra on the hit), concentration and target-scoped effects (Hex), movement/range/reach/line-of-sight legality, rolled grapple escapes (the escape DC displays; ending the effect is manual), incapacitated-ends-grapple (only 0 HP releases), player-invoked `action.resolve`, per-encounter monster death policies, ruleset (2014/2024) declarations and import compatibility levels, structured recharge/legendary actions, and beam-count-by-level expressions (static counts in definitions). Non-turn-scoped always-on attack advantage (e.g. Invisibility) needs a new modifier flag; do not reuse `attack-advantage` for it. What remains is tracked on the roadmap issue.

## Amendment of 2026-07-18 (second slice, same PR)

9. **Reaction prompts.** Declared reactions (`reaction: {trigger: "hit-by-attack", response: "half-damage"}`, as on Uncanny Dodge) become first-class pending prompts on the pendingSaves template: a qualifying hit (structured attack, damage > 0, reactor's reaction free, reactor not incapacitated, mode not freeform) parks its rolled typed damage on `combat.pendingReactions`, away from the runner's apply button. `reaction.answer` (GM anyone; a player their claimed character) applies the damage either halved (the total, rounded down once; use spends the reaction) or in full (decline); the halving happens before defenses, so resistance still applies on top. `reaction.dismiss` (GM) drops a prompt without applying: the escape hatch for damage entered by hand. Prompts persist across turn changes until answered so parked damage is never silently lost; player projections carry only the player's own prompts, source ids stripped and hidden sources masked.
10. **Incapacitation gates the economy.** An actor with Incapacitated (or a condition that includes it: Paralyzed, Petrified, Stunned, Unconscious) violates `condition.incapacitated` for any action, Bonus Action, or reaction, handled by the same strict/assisted/override ladder as every rule.
11. **Available-actions read.** `GET /game/actors/{actorId}/available-actions` (and the `actor:available-actions` socket read) reports per-action availability computed by the _shared_ `evaluateActionEconomy`, the exact evaluation strict resolution enforces, so the report can never drift from enforcement. Rows carry machine-readable violations, uses remaining, and open-instance counts. GM-grade any combatant; a player only their claimed character (availability names stat-block internals). Target-specific rules need a target and are not pre-checked.
12. **Archive v3.** Encounter archives additively gain `postEncounterState`: the state after `encounter.end` ran (combat cleared, end-of-fight effect sweeps and their on-end grants landed). `finalState` (the last live picture) is unchanged; the fight's true aftermath was previously unrecorded.

## Amendment of 2026-07-19 (SRD gap closure, tiers A-D, same PR)

A full cross-audit of the SRD 5.2.1 combat chapter, rules-glossary actions, and conditions appendix against the engine closed the verified gaps in four tiers. Everything below rides the existing machinery: the rules ladder (strict/assisted/freeform with audited overrides), explainable advantage/disadvantage sources, the additive-with-defaults state rules, and the projection allowlists. Where a rule needs a subsystem the app deliberately lacks (vision/light, terrain, hands/inventory), the GM supplies the judgment call as a command input and the server applies the math.

13. **Condition completeness (Tier A).** Every SRD condition now has its mechanical teeth: frightened → attack and ability-check disadvantage (applied whenever active; line-of-sight is GM adjudication, a documented simplification); poisoned → attack and ability-check disadvantage; invisible → own-attack advantage / incoming disadvantage; grappled attacker → disadvantage against everyone but the grappler (source-linked effect names the grappler; a hand-set condition falls back to "grappler unknown" disadvantage against all); paralyzed joins unconscious in the within-5-ft auto-crit; paralyzed/petrified/stunned/unconscious auto-fail Strength and Dexterity saves, a typed d20 included (only the GM's typed total bypasses it, as a ruling); restrained → Dex-save disadvantage; exhaustion applies −2 × level to every D20 Test (attacks, saves, ability checks, initiative and death saves), −5 ft × level to Speed, and level 6 is death; petrified adds resist-all at damage time and immunity to the Poisoned condition (SRD 5.2.1; the 2014 poison damage immunity is gone); `conditionImmunities` (GM-only knowledge, stripped from player projections) skip-with-narration; charmed blocks targeting the linked charmer (`condition.charmed-charmer`).
14. **Builtin generic actions (Tier B).** The eleven 2024 generic actions plus Unarmed Strike variants ship as a code-side catalog (`builtin-actions.ts`, frozen ids, a replay contract) available to every combatant, definition or none; a stat block action with the same id shadows the builtin. Dodge/Disengage/Dash/Help/Ready grant tagged effects with typed modifiers (`voidWhileIncapacitated`: Dodge lapses per the SRD); Influence/Search/Study consume the action and roll the ability check with the skill picked (Search: Insight, Medicine, Perception or Survival; Study: Arcana, History, Investigation, Nature or Religion; Influence: Deception, Intimidation, Performance, Persuasion or Wisdom (Animal Handling), against 15 or the targeted monster's Intelligence, whichever is higher); Magic/Utilize consume and narrate. Every check, the sheet's included, comes from one plan (`checkPlan` in `ability-checks.ts`): proficiency or Expertise, Jack of All Trades, a stat block's printed skill, tool proficiency (Advantage with a proficient skill too), check riders, Exhaustion, Reliable Talent, and Poisoned and Frightened. Hide rolls Dex (Stealth) vs DC 15 → an Invisible-linked Hiding effect, named with the total as the DC to find the creature, that any attack reveals (eligibility, meaning cover, obscurement and sight lines, is GM adjudication). Help distracts an enemy within 5 feet: the next attack roll one of the helper's allies makes against it has Advantage, until the helper's next turn (since the action economy amendment; it once gave an ally Advantage on every attack for the round). Unarmed Strike materializes Str + PB / flat 1 + Str; Unarmed Grapple/Shove force the target's better Str/Dex save vs 8 + Str + PB with a one-size cap, grapples landing as escapable source-linked effects (escape DC = the same formula); Escape Grapple rolls Athletics or Acrobatics, the one asked for or else the better, vs the DC; an incapacitated grappler releases its holds. Ready parks a free-text trigger; the reactor's next off-turn resolve spends the reaction and releases it.
15. **Movement and opportunity attacks (Tier C).** `Actor.speedFeet` (optional: unknown speed skips checks, the unmeasurable pattern) seeds from definitions with a GM `actor.set-speed` command; `turn.movementUsedFeet` accumulates on-turn willing moves against the creature's live Speed (`max(0, max(0, speed − 5 × exhaustion) + the `speed` modifiers its effects carry)`. The reduction floors at 0 where it applies, so a bonus is never eaten by an exhaustion debt, and effects sharing a `stackKey` contribute their single most potent value with no sum, per the SRD's "Combining Game Effects") PLUS the extra-movement grants taken this turn: Dash records `movementGrantFeet` on its effect when the action is taken ("equal to your Speed after modifiers", fixed then); nothing doubles the live Speed on a later read, so a Slow landing mid-turn cannot re-price feet already granted; a `dashing` effect stored before that field degrades to the old doubling. 0 while grappled/restrained/unconscious/paralyzed/petrified ("your Speed is 0 and can't increase" refuses the grant too; Stunned no longer zeroes Speed in SRD 5.2.1); overruns are `movement.exceeds-speed` violations with a GM-only override, and standing from Prone charges half Speed (`movement.stand-up-cost`). Leaving an able enemy's melee reach without Disengaging opens a `leaves-reach` reaction prompt (side heuristic: player-characters vs monsters, npcs excluded; the move completes first; arrival timing is a documented approximation); answering resolves a real melee attack (declared action, first melee, or the builtin Unarmed Strike) against the mover off-turn and auto-applies its damage, which the mover's own Uncanny Dodge can intercept. A hidden mover prompts no one (viewer safety); the GM resolves that retreat manually. Range/reach validate at resolve when measurable: melee beyond reach (`range.out-of-reach`), ranged beyond maximum (`range.out-of-range`), long range and ranged-in-close-combat disadvantage sources (the enemy within 5 feet is a living, able creature on the other side: player characters are the party, any other creature takes its side from its stat block's disposition); the ETL now splits "80/320" into normal/maximum bands.
16. **Cover, concentration, surprise, rests (Tier D).** Cover is GM-selected (no line-of-sight engine), per resolve or as a standing marker the GM puts on a creature from its row tools (an effect tagged `cover-half`, `cover-three-quarters` or `cover-total`), which every attack and Dexterity save against it then reads, a player's included: half +2 / three-quarters +5 to AC and Dex saves, total an overridable `cover.total` block for a single target (a marked creature among an area's targets is a GM note). Concentration: `concentration`-flagged effects are one-at-a-time per source, damage prompts a CON save at DC `min(30, max(10, ⌊damage/2⌋))` whose committed failure ends the sustained effects, and incapacitation or 0 HP breaks concentration immediately. Initiative is one roll for every path (the fight's start, a player's own roll, a mid-fight joiner): Surprise, any Incapacitated condition, Poisoned and Frightened give Disadvantage, Invisible gives Advantage, `roll-mode` riders on initiative or on Dexterity checks (it is a Dexterity check) give either, they cancel per the 2024 rules, and Exhaustion comes off the total. A player can't choose the mode. A score change mid-round never moves anyone across the current turn; the next round sorts fully. Short rests re-arm `per: "short-rest"` and recharge pools and Pact Magic slots, and refill others as item 44 says; healing on one is by spending Hit Point Dice (item 20).
17. **Environment and mercy rules (Tier D niche).** A GM `encounter.set-environment` toggle marks the fight underwater: non-spell melee attacks have disadvantage unless the attacker has a Swim Speed or the weapon deals piercing damage (the SRD's weapon list generalized to its shared damage type), non-spell ranged attacks have disadvantage within normal range and auto-miss beyond it (`range.underwater`), fire resistance for every combatant. `actor.apply-damage` accepts `nonlethal`: a drop to 0 knocks out: at 1 HP and Unconscious (SRD 5.2.1) until it regains hit points, no death saves, no defeat; a named source action that is not a melee attack is refused. The dice panel gains a falling-damage helper (`min(⌊feet/10⌋, 20)d6` rolled server-side, Prone reminder).

Still explicitly unsupported after this amendment (deliberate): mounted combat, jumping, suffocation timers, breaking objects, readying a spell (concentration while held), and vision/light/line-of-sight and auto-derived cover. Underwater speed halving is folded into the GM's speed adjustments and is not automated. Five items this list once held have since shipped in later amendments or changes: hit dice, difficult terrain, two-weapon fighting with the Light property, weapon mastery, and burning (Alchemist's Fire, `hazards.ts`).

## Amendment of 2026-07-19 (Foundry-dnd5e adoption pack: recharge, legendary resources, hit dice; same PR)

A design study of Foundry's dnd5e system (MIT code; studied, never copied) identified three monster/rest mechanics the engine lacked. All three ride the existing machinery: `actionUses` pools, the turn-start hook, the save answer flow, the additive-state and new-command checklists.

18. **Recharge abilities.** `ActionSchema.uses.per` gains `"recharge"` with a 2-6 d6 threshold (a superRefine pins the pairing). The ETL now emits structured pools for what were prose-only names: `RECHARGE_ON_ROLL` → `{limit 1, per recharge}`; `RECHARGE` **with a numeric param** is also a die-range recharge (an upstream data quirk: basilisk/medusa Petrifying Gaze, blink dog Teleport and ten others print "Recharge X-6" in the SRD; the param carries the threshold), leaving one true rest-recharge (cloaker Phantasms) mapped to `short-rest`; `N/Day` maps to `long-rest` (the app has no calendar, so a day is a Long Rest, a documented simplification shared with Legendary Resistance). 86 recharge and 28 rest-scoped pools across the 330-monster bundle; double-printed "(Recharge …)" name suffixes are fixed. At the start of the owner's turn `nextInitiativeTurn` rolls the d6 per spent pool (deps threaded from `initiative.next` and `turn.end` with the audited RNG, which the deterministic test queue drives) and narrates the die either way, to the GM alone for a monster (its resources are GM knowledge; the table sees the breath when it is used); `previousInitiativeTurn` deliberately never rolls (GM correction; the Time Machine is the undo). Encounter start and both rests re-arm pools.
19. **Legendary actions and Legendary Resistance.** `ActionSchema` gains `legendary {cost}` (all 82 SRD rows cost 1) and definitions/actors gain `legendary {actionsPerRound, resistancesPerDay}` (every SRD legendary creature prints 3 per round; the "(4 in Lair)" bump stays prose; 32 creatures carry resistance at the printed non-lair N). The per-round pool is `combat.legendaryUsed` (actorId → spent), refreshed exactly like `reactionsUsed`: the incoming actor's entry clears at its own turn start, in both turn directions, carried through scene park/resume, restored by timeline rewinds, and **stripped from player projections** (monster resources are GM knowledge, the `actionUses` rationale). `evaluateActionEconomy` blocks own-turn use (`legendary.own-turn`: legendary actions happen on other creatures' turns) and over-pool spends (`legendary.no-actions-remaining`) through the rules ladder; a GM-only `turn.use-legendary` sets the pool by hand (the spend path for prose-only legendary actions). Legendary Resistance rides `actionUses["legendary-resistance"]`: `save.answer` accepts a GM-only commit flag that forces the success outcome after a previewed failure; the success consequences (half damage where the save halves) still apply, a natural success spends nothing, and a Long Rest re-arms the daily pool. The tracker offers off-turn legendary creatures as one-tap console switches (⭐ strip) and failed-save previews grow a "Legendary Resistance (N left)" commit.
20. **Hit Point Dice.** `Actor.hitDice {die, maximum, remaining}` (nullable: absent means unmodeled and rests behave exactly as before) seeds from the definition's hit-point formula at roster time. The new `actor.spend-hit-dice` command (GM any actor; players their claimed character) rolls the faces **before** the store executes (the `dice.roll` idempotency pattern), heals `max(1, face + Con modifier)` per die (SRD minimum) through `healActor`'s single-sourced rules, decrements the pool, and lands the dice in the shared roll history (hidden actors GM-only); it is rejected mid-encounter, as the rest guard is. A Long Rest restores all spent dice (SRD 5.2.1 "Regain All HP"); Short Rests still change no HP by themselves; spending is the explicit act. The pool reaches only the owning player and is excluded from the timeline's restorable slice (an out-of-combat resource). The roster grows the previously missing rest UI: GM Short/Long rest buttons and a hit-dice stepper per card, mirrored on the player's own card.

## Amendment of 2026-10-16 (difficult terrain and the movement preview)

21. **Difficult terrain.** The GM paints it per scene on a calibrated grid (`terrain.paint` / `terrain.reset`), stored as disjoint cell-snapped rects (`combat.terrain.difficult`). A token move is now charged along the cheapest 8-way grid path (`movementPath` in `@vtt/rules-5e`), where it once counted endpoint to endpoint: a step costs one cell, or two when any cell of the mover's footprint lands in difficult terrain or in a creature's space that is difficult for it (an enemy that isn't Tiny, per the SRD; player characters and monsters are each other's enemies, NPCs are left to the GM). Hidden creatures never count, so a player's preview can't disagree with the charge. The extra cost doesn't stack. A path can't leave the map to walk round something. Opportunity attacks still compare the move's two endpoints. Painting terrain is scene dressing: it neither dirties the combat timeline nor rewinds with it. Players and the table screen receive only the terrain the fog reveals; terrain under the fog is still charged.
22. **Movement preview.** Dragging a token on a calibrated grid draws the path and its cost from the same function, and the `actor:movement` read reports the budget the move is charged against (counted or not, effective Speed with Dash, feet spent, strict or assisted), so the label reads "35 ft (5 ft difficult) · 5 ft left" or "... too far". The old client-only "Show distance while moving" and "Add 5 ft per occupied square" switches are gone; the preview always shows during a drag, and occupied squares are the rule above.

## Amendment of 2026-10-16 (reaction triggers: AC bonuses and striking back)

23. **AC reactions.** `reaction` widens from one shape to four (`ActionReactionSchema`): `half-damage` (Uncanny Dodge) as before, `ac-bonus` (`amount`, optional `melee`, optional `untilNextTurn`), and two `damaged-by-creature` responses below. A committed attack that would hit a target holding an affordable `ac-bonus` reaction stops at its roll when the bonus would turn it into a miss: the attack's economy is spent, nothing past the roll happens, and an `attack-would-hit` prompt holds the attack (`parkedAttack`, GM-only: the action, the kept die or typed total, cover, slot, distance and who rolled it). Answering finishes it with the same die (`economyPaid` skips the economy the second time): "use" first spends the reactor's reaction and the action's own cost (Shield's slot, Protective Magic's use), then adds the bonus against this attack (Parry) or grants an effect carrying `armorClassBonus` until the reactor's next turn (Shield), read through `armorClassInPlay` by the attack roll and the sheets. A hit's damage then applies like an opportunity attack's, so the GM's apply button and manual damage entry don't apply to it. A critical hit is never offered (it lands whatever the AC). Parry, Riposte and Whirlwind of Sand are read from stat-block prose (`acReactionOfProse`, melee when the trigger names a melee attack); Protective Magic, the Shield spell and the builder's spell actions declare it.
24. **Striking back.** `damaged-by-creature` with `strike-back` resolves the declared action against the creature that dealt the damage (Hellish Rebuke's save, Storm's Thunder's damage); with `melee-attack` it makes one melee attack, picked like an opportunity attack's and spending the reaction even on the reactor's own turn (Retaliation, now modeled). The prompt opens wherever damage applies with a known source creature (`DamageInput.sourceActorId`: the GM's apply, a player's direct or confirmed hit, a save's outcome, a reaction's own damage), only while the source is public, alive and in the fight, the reactor could take the action, and the map doesn't show the source beyond `rangeFeet` (an unmeasurable distance is the table's call). A second hit while one waits opens no second prompt. Counterspell, Feather Fall, Stone's Endurance and reactions protecting another creature stay prose.

## Amendment of 2026-10-16 (the last three weapon masteries, and the Light property)

25. **Light and Nick.** Each equipped Light weapon, once two are in hand (another weapon, or a pair of the same), gets an engine-minted extra attack (`extraAttack: {kind: "light"}`, id `item-<id>-light`): usable after an attack with a different Light weapon in the Attack action this turn (recorded in `turn.extraAttacks`, never projected), once per turn across all of them, its damage without a positive ability modifier unless the bearer has Two-Weapon Fighting. It costs the Bonus Action, or nothing when the weapon making it has Nick (part of the Attack action). It carries the weapon's own mastery. The 2026-07-19 line that kept two-weapon fighting and the Light property unsupported, and weapon mastery with them, is superseded.
26. **Cleave.** A melee hit with a Cleave weapon opens its `-cleave` swing, offered on the result card: once per turn, at another creature within 5 feet of the first (checked when the map can measure) and within reach, spending no action, its damage without a positive ability modifier.
27. **Vex.** A hit that deals damage (after the target's defences) lays a "Vexed by" marker on the target, linked to the attacker; the attacker's next attack roll against it has Advantage and spends the marker, hit or miss. It lasts until the start of the attacker's turn after next, a turn of opportunity attacks longer than the SRD's "end of your next turn", since effects expire only at turn starts. Slow likewise needs a hit that deals damage, and Sap's Disadvantage is spent by the sapped creature's next attack roll.
28. **Graze lands.** A miss carrying Graze damage now owes it like a hit: the GM's apply button, a player's proposal or direct damage, and an opportunity attack or a finished parked attack all apply it. It used to show on the card and go nowhere.

## Amendment of 2026-10-16 (extras on a hit, damage with no attack roll, printed monster damage)

29. **Extras ride the hit.** Sneak Attack, Divine Smite, Searing Smite, Shining Smite, Divine Strike, Primal Strike and a monster's printed charge are offered on an attack's preview (`hitOffers`) and chosen with its confirm (`hitOptions`, with a damage type or a slot where the extra takes one). Their dice join the hit's damage, so a crit doubles them and the target's defences meet them as one hit; their costs (a per-turn use, a slot, the Bonus Action) are spent with the hit, and a miss spends nothing. The server checks each: the weapon (Finesse or Ranged for Sneak Attack, a Melee weapon or an Unarmed Strike for a smite, any weapon for the strikes), the turn ("once on each of your turns"), and Sneak Attack's Advantage, or an able ally within 5 feet of the target and no Disadvantage. Where the map can't measure, the offer says so and the attacker vouches for it. Sneak Attack takes the weapon's damage type; Divine Smite adds 1d8 against a Fiend or an Undead; Shining Smite marks the target with an effect that gives attacks against it Advantage; Searing Smite leaves an effect that burns again at the start of each of the target's turns (item 33). Taken alone, any of them is the overridable `attack.rides-a-hit` block; an extra the hit can't carry is `attack.hit-option-unqualified`. The riders are a code-side table keyed by action and spell id, so sheets built earlier get them too. A parked attack (Parry, Shield) carries its chosen extras to the replay.
30. **Damage with no attack roll and no save** (Magic Missile) is owed to each target like a hit's (`damageTargets`, each with its own typed parts): the GM's card has an Apply per target, and a player's lands as a proposal or directly, per the table's player-damage mode.
31. **Monster damage as printed.** The ETL reads each attack's damage from its printed hit clause (the open5e rows dropped extra damage on 91 attacks and had wrong dice on 7), fixed amounts ("1 Piercing damage") included, and its conditional damage as `conditionalDamage`: Advantage, its own or the target's Bloodied, the target Grappled by it, applied by the engine; and a charge, which the engine can't see, offered on the hit. A save action deals at once only what the first sentence of its failure prints; damage at the start of later turns (swallow, engulf) is the save's `ongoingDamage` (item 33), and what the engine can't deal (an infernal wound's lost hit points) and failures that turn on the target's Hit Points become the action's `reminder`, shown to the GM when it resolves.

## Amendment of 2026-10-16 (conditions, effects, durations and Concentration)

32. **Every imposed condition has a source and an end.** A failed save's conditions land as one source-linked effect (`failureEffectFor`, applied by `applyFailureEffect`), so Charmed knows its charmer and Grappled its grappler. Prone (ended by standing) and Exhaustion (cumulative: each time it is received adds a level, from any path) stay bare. The save block carries how the conditions end, read from the SRD text at build time (`save-outcomes.ts`) or authored on class features and items: `failureDuration` ("for 1 minute", "until the start of the X's next turn", "until the end of its next turn" (the target's), "until the end of your/the X's next turn" (the source's)), `repeatSave` ("repeats the save at the end of each of its turns"), `escapeDc` and `rangeFeet` for a grapple (its "Restrained until the grapple ends" companions ride the same effect), `endsOnDamage`, `speedZero`, "while X, also Y" companions (Hypnotic Pattern's Incapacitated, a chuul's Paralyzed), `failsAtHitPoints` (Power Word Stun: no save at the cast), and `ongoingDamage` ("takes 21 (6d6) Acid damage at the start of each of the behir's turns": the dice, and whether it is the target's turns or the source's). On-hit riders carry the same `duration` and grapple companions; one the hit's sentence gives with no end lasts until ended (an otyugh's Poisoned, which a save after a Long Rest ends). Effects gain the matching durations `until-bearer-turn-end` / `until-source-turn-end` (with `skipsCurrentTurn` when they begin on that creature's own turn) and the fields `repeatSave`, `endsOnDamage`, `speedZero`, `castId`, `rangeFeet` and `ongoingDamage`.
33. **The ends and starts of turns are steps.** `nextInitiativeTurn` runs `endOfTurn` (`turn-boundaries.ts`) for the outgoing combatant before the next begins: turn-end durations it owns lapse, then each repeating effect it bears opens its save as a pending save whose success ends the effect (`repeatOf`). Once the incoming combatant's durations tick, `startOfTurn` deals each effect's `ongoingDamage` that falls on that turn, the bearer's own or the source's (a source at 0 HP deals none): the dice roll on the server and the damage meets the bearer's defences, temporary hit points, Concentration and death saves like any other. An effect whose damage is followed by a save (`saveToEnd`, Searing Smite) opens it then, a success ending the effect. The dice stay with the GM: players see the effect and the damage when it lands. Damage printed for the end of a turn, and hit point loss, stay with the GM. The GM's backward step runs none of this.
34. **Casting a Concentration spell starts Concentration.** The resolve step `startConcentration` gives the caster "Concentrating on X" (`concentrating` tag, `concentration`, the spell's duration up to 100 rounds, else until ended) and a `castId` every failed save of that cast shares; starting another ends the caster's others (one at a time), and ending the caster's effect ends the whole cast. A Concentration smite chosen on a hit (Shining Smite) starts it the same way, its mark on the target sharing the `castId`. Damage asks for the Constitution save in or out of a fight; Incapacitation from any path (`conditionGained`, shared by every condition writer), 0 HP, a GM HP edit to 0, Exhaustion 6 and a Long Rest's sleep end it. A save answered after the Concentration broke imposes nothing. A GM-added concentration effect may name its caster as `sourceActorId`.
35. **Implied conditions and their ends.** Unconscious brings Prone (which stays after it); Petrified drops and refuses Poisoned; Dodge lapses at Speed 0 too; a knocked-out creature wakes when it regains hit points; an effect ending leaves a condition also set on its own (`standalone`).
36. **Who may end what.** The GM ends anything. A player adds conditions to their character and takes off only what they added (`selfApplied`); a condition or effect imposed on them is a `condition.imposed` block (economy family) they can ask the GM about (`effect.end` is now askable), and standing from Prone off their own turn is `movement.stand-up-off-turn`. A player may end any effect their character is the source of, on any creature (a released grapple, a dropped Concentration); the player projection marks those `yours` and strips `castId`.
37. **Incapacitation reaches every activation.** Legendary actions and `activation: "other"` feature activations (Sneak Attack, Reckless Attack, Action Surge) are refused while Incapacitated or at 0 HP through `condition.incapacitated` / `condition.down`, except the few that answer a roll or an event (Indomitable, Relentless Endurance). Rage lasts until the end of the Barbarian's next turn, extended by an attack roll or forced save against another creature or by re-declaring it as a Bonus Action (no use spent), ends on Incapacitation or in Heavy armor, ends the Barbarian's Concentration and refuses spells (`condition.raging`). Danger Sense and the Paladin auras are gated on not being Incapacitated.
38. **Fight's end and rests.** Encounter end and a Long Rest end only effects measured in turns or rounds (and the rester's Concentration); "until ended" effects (a curse, a grapple still held, an hour-long Concentration) outlast them. Opportunity-attack prompts need sight: none for an Invisible mover or a Blinded reactor unless its Blindsight (or, for Invisible, Truesight) reaches. A grapple ends when a move takes the two farther apart than its range. Each turn opens with a reminder line listing the incoming combatant's conditions and effects, with source and time left.

Still open after this amendment (Rage's cap, Persistent Rage, Fast Movement and Roving closed by item 56, the swallowed creature by item 58, spell restraints' escape by item 59): Rage's 10-minute cap and Persistent Rage's longer form, the second stage of two-stage saves (a basilisk's Petrified, Sleep's Unconscious), escape checks for spell restraints (Entangle, Web), Fast Movement and Roving in Heavy armor (their Speed is baked into the sheet), and ending a swallowed creature's conditions when the swallower dies.

## Amendment of 2026-10-16 (spellcasting: slots, casts and what spells leave behind)

39. **Spell slots.** A leveled spell's cast spends one slot when it starts, at the level asked (`slotLevel`; absent, the lowest at or above the spell's level with one left). Pact Magic is its own pool (`pactSlots`, every slot at the Warlock's slot level), refilled by a Short or a Long Rest and shown as its own pips; a multiclass caster spends either pool on either class's spells, a pact slot first at a level both pools have. The `slots` family checks one slot per turn (`slots.one-per-turn`, cantrips and slot-free casts aside), none below the spell's level, none from an empty pool and only a prepared spell (`slots.not-prepared`; the Long Rest prepare step is ADR-0021's), and follows the campaign's rules dial like every family (Enforce refuses and offers the GM an Allow, Advise warns); the GM's "Don't police spell slots or prepared spells" makes it freeform on the sheet and outside a fight too. A prepared ritual spell also casts as a Ritual without a slot (`spell-<id>-ritual`). A casting time of a minute or more takes the Magic action on each of its turns, is refused while Incapacitated, and spends its slot when it starts; the cast reminds the GM.
40. **Casts.** A spell with several attack rolls (Scorching Ray, Eldritch Blast's beams) opens its own component keyed by the action (item 3's generic `attack` pool is the Attack action's alone), so a swing never comes out of a spell's rays nor a ray out of Extra Attack; every ray rolls at the cast's slot, and a higher slot adds rays and Magic Missile's darts. Darts (`darts`) roll one by one and strike the targets listed in order, a target named twice taking two, so each target is owed only its own darts (`damageTargets`, item 30). A spell attack takes its range and its melee or ranged kind from the spell (a spell attack is never a weapon's: `melee-weapon` and `ranged-weapon` are a `weapon` attack made in melee or at range); a save or healing spell checks its range and how many creatures it targets at this slot (`range.out-of-range`, `target.too-many`); Sacred Flame's save ignores cover (`ignoresCover`); the caster picks Chromatic Orb's damage type (`damageTypes`). A save made later, or never by the target (Spirit Guardians, Haste), prompts none at the cast; what a spell lets its caster do later is its own action (`spell-<id>-then-<name>`), offered while the spell lasts (item 66), and an area that acts later is run by the server (item 65); the cast reminds the GM of the rest. An area catches its caster when the template covers it (an Emanation, Cone or Line from the caster never does), and a healing area heals the creatures the caster picks, up to its count.
41. **What spells leave behind.** A spell's cast model (`SpellReference.effect`) carries a `grant` for the creatures the cast targets (`target: "targets"`, Bless) or the one its attack hits (`onHit`, Guiding Bolt's light), with `armorClassBonus` while it lasts (Shield of Faith, Haste; read by `armorClassInPlay`), and a save's `failureEffect` (Bane, Faerie Fire); the character build copies them onto the spell's action (`ActionGrantSchema`, `save.failureEffect`), and an older sheet's spell action gets them when it resolves. `attack-bonus` and `save-bonus` riders may carry signed `dice` ("1d4", "-1d4"): a save rolls them in, and an attack rolls them once it is made for real, shows them still to roll in a preview, and keeps them through a parked attack. A `by-effect-source` filter lets an effect's riders fire only for the creature that put it on the bearer, so Hunter's Mark and Hex add their 1d6 to their caster's hits on that creature alone. One spell's effects on a creature share a `stackKey` (`spell:<id>`) and count once, AC included. Guiding Bolt's light ends with the next attack roll against the creature, whoever makes it (`until-attacked`); Faerie Fire's outline (`outlined`) takes away the Invisible condition's benefit. Mage Armor and Haste measure the creature when they land (13 + Dexterity, nothing in armor; Speed doubled). The effects carry the spell's own duration, and a Concentration spell's share its `castId` (item 34, the grant running after `startConcentration`, the failure effect through `failureEffectFor`), so they end with the caster's Concentration. The line above listing target-scoped effects (Hex) as unsupported is superseded.

## Amendment of 2026-10-16 (death, stabilizing and rests)

42. **One "dead" rule.** `isDead` (`packages/domain`) decides it for every path: a character on a third failed death save (massive damage counts as three), anyone at Exhaustion 6, and a monster or NPC at 0 HP (SRD Monster Death) unless it lies Unconscious there. A dead creature regains nothing: healing (an `actor.heal`, or a spell's or feature's heal that reaches only the dead, before its slot or points are spent; one that also reaches the living narrates the skip for each dead target) and a GM `actor.set-hp` above 0 are refused, and no rest or Hit Die applies. The only way back is the GM-only `actor.revive` with the hit points the revival gives: the dying state and its Unconscious end, Exhaustion drops a level, attunement ends, other conditions stay. A rest and spending Hit Dice need at least 1 HP (SRD Resting), so item 8's "dying reset" no longer happens on a Long Rest. A rebuild leaves a character at 0 HP at 0, so a level up never revives one either.
43. **Stabilizing.** `actor.stabilize` makes a dying creature Stable (counters reset, Unconscious kept) by the aid a helper gives: first aid, a DC 10 Wisdom (Medicine) check the server rolls with the helper's sheet bonus, Exhaustion and check riders (`stabilize.ts`; the check package will own the general check roll); a Healer's Kit, which spends one use from any carried kit's quantity, the way a potion is used up (`withOneUsedUp`); or Spare the Dying, which the helper must know. The GM may rule it with no helper. First aid also wakes a knocked-out creature ("someone ... administers first aid"). In a fight the aid is the helper's action on its own turn, within 5 feet (Spare the Dying: 15 feet, doubling at levels 5, 11 and 17), through the rules ladder; a player helps only with their own character, on a creature they can see. The turn order offers it under a dying creature's pips (the GM picks the helper, a player helps on their own turn), and outside a fight the sheet and the player's party list do.
44. **Short-rest recharges.** A Short Rest also re-arms per-encounter pools (Boon of Fate is spent "until you roll Initiative or finish a Short or Long Rest"), and gives a long-rest pool back what a `short-rest-regain` rider on the character's features names: one use of Rage, Second Wind, Channel Divinity (Cleric or Paladin, one between them) and Wild Shape, and every Bardic Inspiration once Font of Inspiration (Bard 5) arrives. The rider is read from content when the rest ends, so sheets built earlier get it too, and two riders on one pool give the larger of the two.
45. **Long Rests wait for the GM and the clock.** The game keeps its own clock in whole hours (`rest.clockHours`; the Codex calendar counts days in its own store, so the two are separate for now). The GM moves it (`time.pass`), a party Long Rest moves it 8 hours and a party Short Rest 1. Each creature records the hour its last Long Rest ended (`lastLongRestAt`), and every Long Rest path refuses another until 16 hours later (SRD Resting), saying how long is left ("Torva finished a Long Rest 10 hours ago - another can start in 6 hours"). A player no longer takes a Long Rest: they ask (`rest.ask`, refused at once for the same reasons), and the GM approves, which rests them now, or turns it down (`rest.answer`). Short Rests stay theirs to take. The GM rests the party together (`rest.party`): all the chosen characters or none, the refusal naming who can't and why. A Long Rest happens at once; a Short Rest opens on each player's device with their Hit Dice to spend and a Done button (`rest.mark-done`), and lands when the GM finishes it (`rest.finish`), an hour later, for whoever can still rest; rolling Initiative, taking any damage or casting a spell other than a cantrip takes a member out of it with no benefits (SRD Interrupting the Rest), and the last two say so on the table feed. Players receive only their own characters' requests and place in the Short Rest; the clock and `lastLongRestAt` stay with the GM. Passing time does nothing else: timed effects and Concentration are still the GM's to end.
46. **Monsters and NPCs rest too.** Their sheets give the GM both rests, without Hit Dice to spend; a Long Rest re-arms Legendary Resistance and per-day uses (which are long-rest pools), and the 16-hour rule and the dead rule apply as to anyone.
47. **Pools spent by any amount.** An action can cost several uses of its pool (`useCost`: a number, or `chosen` with the amount sent as `spend` on the resolve or the loose route), and the limited-use check refuses what the pool can't pay ("Lay on Hands has 18 left - this spends 30"). `healing.perUse` regains the formula once per use spent, and `endsConditions` ends conditions on the target, refused when it has none of them. Lay on Hands is a pool of five points per Paladin level with two Bonus Actions: heal (the runner asks how many points) and cure a poison (5 points); Superior Defense costs 3 Focus Points and Quivering Palm 4. A character's player spends several uses of any pool at once (`actor.spend-uses`) and the GM gives uses back (`actor.restore-uses`), for the features that refill a pool (Uncanny Metabolism, Persistent Rage, Sorcerous Restoration), the Metamagic options that cost 2, and rulings; the sheet lists each pool with what is left. A pool holds up to 100 uses. Restoring Touch's other conditions stay prose.
48. **A land chosen after a Long Rest.** A rest-time re-choice the build itself reads (its options grant spells, or another pick depends on it) goes into the choices ledger, and the sheet is rebuilt from the ledger as a level-up rebuilds it, keeping what has been spent (`ledger-rechoice.ts`). So a Circle of the Land Druid's land brings that land's spells for its Druid level and lower, Nature's Ward's Resistance follows it, and the land stands until it is chosen again. A player chooses in the prepare step a Long Rest opens, where the sheet's Spells section offers it; the GM may choose any time outside a fight. Other re-choices (Fiendish Resilience's damage type) stay runtime overrides cleared by the matching rest.

## Amendment of 2026-10-16 (action economy and movement)

49. **Turns.** An action or a Bonus Action off the creature's own turn is the `economy.not-your-turn` block on every path (`action.resolve` from the map's targeting as well as `action.use`), overridable by the GM and askable by a player; the message names the current creature only when the table can see it. A Readied creature's response off its turn is its Reaction: it spends the Reaction, and with none left it is the `economy.reaction-used` block, so nothing releases for free. A player's Ready trigger reaches the effect's name, as the GM's does. Only the GM gives back a spent action, Bonus Action or Reaction (`turn.use`, `turn.use-reaction`): a player's un-marking is the `economy.spent-slot` block, a GM note when advised, and the player's toggles lock a spent slot while the economy is policed. The Unarmed Strike options (damage, Grapple, Shove) are attacks of the Attack action (`replacesAttack`): one opens it with Extra Attack's other attacks left, or spends one a weapon swing left. A second Dash in a turn adds its extra movement to the first. Help puts its mark on the distracted enemy (`distracted`, the `target.not-an-enemy` and `range.out-of-reach` blocks guarding who and how far), and the first attack roll against it by an ally of the helper reads and spends it, an opportunity attack included.
50. **Bonus Action forms.** A feature that lets a creature take a generic action as a Bonus Action gives it a builtin row of its own, `<id>-bonus`, named for the feature ("Cunning Action: Dash"), resolved by the generic action's handler and journaled by that id (`builtinActionsFor`): Cunning Action (Dash, Disengage, Hide), Martial Arts (an Unarmed Strike, any of its options, with the Monk's own numbers and as one attack), the free Dash of Step of the Wind and Disengage of Patient Defense, and a stat block's "takes the Disengage or Hide action" (Nimble Escape, Deathless Agility). They are read from the sheet's features and actions, so sheets built earlier get them. A row that takes two generic actions at once (the Focus Point forms of Step of the Wind and Patient Defense, a clay golem's Hasten) grants both effects as one (`withTakenActions`). Players take the generic actions from their own console as the GM does, and Sneak Attack, a smite and the strikes are pointed at a hit's result, so none is offered as a tap the server refuses (`ridesAHit`).
51. **Actions beyond the one.** Action Surge (keyed by its action id, so earlier sheets get it) gives one additional action on the creature's own turn, once on a turn even with two uses (`feature.once-per-turn`); it can't be a second Magic action. Haste gives an additional action on each of the target's turns, which takes only the Attack action (one attack only), Dash, Disengage, Hide or Utilize. Either takes the place of the `economy.action-used` refusal, opening a fresh action (a Loading weapon fires again in it); the turn records them engine-side (`turn.extraActions`), and the table sees `extraActionReady`. When Haste ends, its target is Incapacitated with Speed 0 until the end of its next turn (`Lethargy`), unless a fight's end or a rest swept it away.
52. **Opportunity attacks.** The answer to a `leaves-reach` prompt, and Retaliation's, is one melee attack with a weapon or an Unarmed Strike, any of its options (Grapple and Shove keep their size rule); a ranged attack, a spell, a Multiattack plan, a legendary action or an extra attack is refused and the reaction kept. Its preview offers the extras its hit can carry (Sneak Attack, "once per turn", on the mover's turn), chosen with the confirm (`hitOptions`). An Unarmed Strike taken as a Bonus Action counts as unarmed for every rule that asks.
53. **Multiattack as printed.** The SRD ETL reads a Multiattack's whole sentence (`multiattackOfProse`), so 177 of 178 are structured (the hydra's head count stays prose, item 2's degradation): a place either of two actions fills ("two attacks, using Scimitar or Shortbow in any combination", a component's `or`, keyed `a|b` in the open instance), another plan (`multiattackAlternatives`, "or it makes two Hurl Flame attacks", which the first action of that plan switches to while nothing of the first is taken), and an action that takes an attack's place (`multiattackReplacements`, "it can replace one attack with a use of Roar", the attack it names or any attack, once or for each). The open instance records its Multiattack (`parentId`) and the replacements left, engine-side; a player's projection keeps only the components.
54. **Legendary actions as printed.** A legendary action that "can't take this action again until the start of its next turn" (`legendary.oncePerRound`) is the `legendary.once-per-round` block once taken, its mark kept in `combat.legendaryUsed` as `<actorId>:<actionId>` and cleared with the pool at the creature's turn start. A legendary action that makes another of the stat block's attacks or uses another action ("makes one Rend attack", "The kraken uses Lightning Strike") carries that action's attack, save and damage from the build; one with nothing to roll (Commanding Presence) spends the pool when used, and the off-turn console gains a spend button beside the correction, so item 19's spend path by `turn.use-legendary` is now the fallback. "Can't be targeted by the tyrannosaurus's Tail" while its Bite grapples becomes a `targetRules` entry, as the crocodile's.
55. **When class features are taken.** Reckless Attack's Advantage is on attack rolls using Strength (`ability-is`), and it is decided with the Barbarian's first attack roll on its turn: off that turn it is the `economy.not-your-turn` block, after an attack roll there the `attack.after-first-roll` block (the turn records `attackRolled`, engine-side). Steady Aim is the `movement.already-moved` block once the Rogue has moved this turn; its effect lasts to the end of the turn with Speed 0, and the next attack roll spends its Advantage. Stunning Strike is once per turn beside its Focus Point (`feature.once-per-turn`, counted in the turn's uses). All three are read by their effect tag or action id, so sheets built earlier get them, a Reckless Attack grant without the Strength gate narrowed as it lands.
56. **Limits and lasting effects the SRD times.** A use that comes back "until the start of your next turn" (Peerless Aim) has its own scope, `uses.per: "own-turn"`: it stays spent through the other creatures' turns and comes back as the bearer's turn starts or a fight begins; outside a fight it is no limit, like a per-turn one. Rage is extended for up to 10 minutes, 100 rounds from the round it began, which a re-declared Rage keeps; under Persistent Rage it lasts the 10 minutes outright and only Unconscious (or Heavy armor) ends it early, and the feature's once-per-Long-Rest use regains every expended Rage. Fast Movement and Roving keep their +10 in the sheet's Speed and take it back live while Heavy armor is worn (a gated -10), so sheets built earlier need no rebuild. A Power Word Stun target over 150 Hit Points has Speed 0 until the start of the caster's next turn, an effect from the caster, where it was a note. Hunter's Mark and Hex carry a later action, `move` (`movesGrant`): a Bonus Action that moves the cast's mark from a creature at 0 Hit Points to a new one, still held by the same Concentration, the `target.mark-still-standing` block while the marked creature stands and `feature.requires-effect` with no Concentration on the spell. A later action of a Concentration spell (Spirit Guardians' save) no longer starts a new Concentration that ends the cast's own.
57. **Moving on the map.** `token.move` takes a `mode`: walking, a special speed (`fly`, `swim`, `climb`, `burrow`), `teleport` or `forced`. Special speeds come from the stat block (and Roving's Climb and Swim Speeds equal to Speed); each way of moving has its budget, Dash's extra movement coming in that speed, and the movement already spent this turn comes off whichever is used (SRD "Special Speeds"), flying or burrowing without the speed being the `movement.no-speed` block. Crawling while Prone, and climbing or swimming without the speed, cost an extra foot per foot (two in Difficult Terrain), as does dragging a grappled creature that isn't Tiny or two sizes smaller, which moves along with its grappler and keeps the grapple. Teleportation and forced movement spend nothing and provoke nothing; only the GM moves a creature by force. Another creature's space is open ground if it is an ally or Tiny, otherwise Difficult Terrain that bars the way unless the creature is Incapacitated or two sizes apart (`spacePassage`), and a move may not end in another creature's space (`movement.occupied`); with no way through it is the `movement.blocked-path` block. Opportunity attacks are read along the whole path, so running past an enemy provokes, and sides are `areEnemies`', as attacks' (superseding item 15's player-characters-versus-monsters heuristic and item 21's endpoints and difficult-only spaces). In a fight, a player's move off their turn (`movement.off-turn`) or teleport (`movement.teleport`) is the GM's to allow, by the map's "Ask the GM", and only the GM takes a placed token back to the tray. `actor:movement` reports each mode's budget, crawling and dragging; the map offers the modes as one-tap chips under the board, and its preview mirrors all of it.
58. **Leaving the fight.** The GM takes a combatant out of a running fight (`encounter.remove-combatant`): when it is its turn the turn moves on first, recorded like any other; then its initiative entry, token, prompts and per-round marks go, what it sustains ends (its grapples, its Concentration, what lasts until its next turn), and it stays on the roster. The last combatant ends the encounter instead. A swallower that is defeated or taken out lets its prey go as its stat block says: the swallow's effect ends, and the prey climbs out with the movement named ("escape from the corpse by using 20 feet of movement, exiting Prone"), Prone, out of this turn's movement on its own turn, otherwise as Speed lost until the end of its next turn.

## Amendment of 2026-10-17 (monster traits and spellcasting)

59. **Magic Resistance.** A save against a spell or a magic item's action is marked `magical` (`PendingSave.magical`, carried onto the effect its failure leaves, so a repeated save keeps it; never projected to players). A creature holding Magic Resistance makes it with Advantage, named on the roll; Greater Magic Resistance (the rakshasa) succeeds without a roll (`autoSucceeded`), and spell attack rolls miss it, said to the GM only. A monster action the text calls magical (a sphinx's roar) isn't marked: the GM forces Advantage.
60. **Advantage from traits.** Read by trait name, as Evasion is: Pack Tactics (an able ally of the attacker within 5 feet of the target, from the tokens; nothing where the map can't measure), Bloodied Fury and Bloodied Frenzy (attack rolls, and the berserker's saves, while Bloodied), Blood Frenzy (against a creature missing hit points) and Aura of Authority (the hobgoblin captain and its allies within 10 feet, attacks and saves, while it isn't Incapacitated). A hidden ally or captain never gives a visible creature Advantage.
61. **Traits the engine runs.** The SRD build reads what a trait does from its printed text into `ActorDefinition.traitMechanics`, and the engine runs it. Regeneration heals at the start of the creature's turn, except the turn after it took one of the types that stop it (a `regeneration-stopped` mark lasting through that turn), and only at 1 Hit Point or more for the oni; the troll at 0 lies Unconscious under a `regenerating-at-zero` effect (so `isDead` says no) until its turn starts, when it regenerates or dies. Undead Fortitude rolls its Constitution save on the server as the damage lands (DC 5 plus the damage taken, none against Radiant or a Critical Hit; `DamageDeps.rollDie`). Auras act at the end of their bearer's turn (Fire Aura and Heat Aura: damage rolled once, to its enemies when the text says "of its choice", setting what a fire elemental's reaches burning), on each creature that starts its turn in them (Stench, Fear Aura, Gibbering: a save prompt whose failure lasts `until-bearer-next-turn`, a new duration, and whose success, where printed, makes it immune to that creature's aura for the fight, where the SRD says 24 hours; the mouther's d8 table goes to the GM), or at the start of the bearer's turn on what it grapples or is grappled by (Barbed Hide). Every aura is silent while its bearer is down, or Incapacitated where the text says so, and reaches no one when the map can't measure (the GM is told what it deals). Death Burst and Death Throes open their saves for the creatures in reach as the creature dies, the damage rolled once. Corrosive Form burns a creature that hits it with a melee attack roll. Berserk rolls its d6 when the golem starts its turn Bloodied and ends when it no longer is. The turn advance now reads where creatures stand (a map that can't be read leaves every distance unknown).
62. **Monster spellcasting.** The build reads each Spellcasting action's At Will and N/Day lists, and the spells other actions cast (a 3/Day Misty Step, Divine Aid's choice, a legendary "uses Spellcasting to cast Fear", an ice devil's Wall of Ice at level 8), into `castsSpells`: the ability and the printed save DC and attack bonus (8 + PB + modifier, and PB + modifier, where it prints none) and each spell with its level and per-day uses. As the catalog loads (`withMonsterSpells`), every listed spell becomes a cast action after its list with the spell's attack, save, damage, healing and effects from its record (`spellCastMechanics`, as an item's cast), with no slot: at will, N uses a Long Rest gives back, or the parent action's own uses; an action that casts one spell becomes that cast and keeps its cost. A Multiattack's use of Spellcasting names the cast it means (a cast at another level joins the list, "Acid Arrow (level 3)"), or any of the list where the text names none. The GM's action list shows each list with its numbers and a row per spell. The pit fiend's Hellfire Spellcasting (two Fireballs in one action) stays prose.
63. **What lingers after a hit or a failed save.** An on-hit rider can carry `ongoingDamage` and a `name` without conditions (a stirge attached, draining at the start of each of its turns; a cloaker attached, blinding) and land `insteadOfDamage` (a rug's smothering grapple, which always smothers a creature it can). `ongoingDamage` can fall as a turn ends (`bearer-turn-end`, `source-turn-end`) and can be `hitPointLoss`: an infernal wound loses the bearer hit points at the start of its turns, which is no damage (no type, defence, Temporary Hit Points or Concentration save), lasts a minute, and ends when a spell restores the bearer's hit points (`endsOnSpellHealing`); stanching it is the GM's, from the action's reminder. This supersedes item 33's last sentence on end-of-turn damage and hit point loss; the giant toad's Swallow, a prose action with no roll, still leaves its end-of-turn acid to the GM.
64. **Traits that change how a creature moves.** Flyby provokes no Opportunity Attack when the creature flies out of reach, and Agile none at all; Abduct drags a grappled creature at no extra cost; Air Form, Fire Form, Water Form and Swarm let a creature end its move in another creature's space, and anyone may end one in a swarm's, passing through as Difficult Terrain on the server's path (the drag preview doesn't know these traits yet). Spider Climb, Web Walker, Ice Walk, the leaps, Tunneler, Earth Glide, Amorphous and Incorporeal Movement name terrain the map doesn't model and stay reference.

## Amendment of 2026-10-17 (spells that act after the cast)

65. **Spell areas.** A cast whose spell leaves an area acting on creatures later (Spirit Guardians, Moonbeam, Cloudkill, Incendiary Cloud, Insect Plague, Black Tentacles, Blade Barrier, Wall of Fire, Wall of Thorns, Web, Stinking Cloud, Sleet Storm, Grease, Spike Growth, Flaming Sphere, Guardian of Faith, Zone of Truth, Conjure Animals, Conjure Woodland Beings) opens a zone (`combat.spellZones`, GM-only): on the template the GM placed with the cast, around the caster for an Emanation, or waiting for the GM to place it (`spell-zone.place`, from the fight panel's Spell areas) when a player cast it. The trigger is the spell's content (`laterActions[].zone`: entering, starting or ending a turn there, or travelling in it; once per turn; the caster's enemies only; a damage cap). The server watches a token's path (`token.move`, a dragged creature's too), the area being moved (`annotation.move`) or carried by its caster, and the end and start of each turn (`nextInitiativeTurn`), and the creature makes the save (a pending save, its damage rolled then at the cast's level, its failure held by the caster's Concentration) or takes the damage (Wall of Fire; Spike Growth's 2d4 for every 5 feet travelled in it). Entering counts once a turn; "only once per turn" counts every trigger. A zone ends with the Concentration holding it, at its duration (a spell without Concentration, at its caster's turn), at the fight's end, when Guardian of Faith has dealt its 60, or by the GM (`spell-zone.end`), and its area leaves the map with it. Stinking Cloud's Poisoned lasts to the end of that turn and bars actions and Bonus Actions (`no-actions`, the `condition.incapacitated` block), Sleet Storm's failure also breaks Concentration, and Web's, Entangle's and Black Tentacles' restraints are escaped with an action and a Strength (Athletics) check against the spell save DC (`escape-athletics`: Escape takes Athletics alone). A wall is placed as a 5-foot-wide Line; a ringed wall, Wall of Fire's burning side out to 10 feet, and a cloud's 10-foot drift (the GM is reminded at the caster's turn) stay with the GM, and Spirit Guardians' designated creatures are the caster's allies. An area that halves the Speed of the creatures it affects (`halvesSpeed`, Spirit Guardians) makes each step a mover takes inside it cost double (`movementPath`'s `isHalved`, difficult terrain included); the move preview doesn't know of it, so the server's charge is the one that counts.
66. **Later actions while the spell lasts.** A spell that lasts and lets its caster act again (Spiritual Weapon, Arcane Sword, Conjure Fey, Flame Blade, Produce Flame, Flaming Sphere's ram, Heat Metal, Call Lightning, Sunbeam, Vampiric Touch) is up on its caster: its Concentration effect names the spell and the level it was cast at (`EffectInstance.spell`), and a spell without Concentration leaves an effect of its own for its duration (casting a cantrip such as Produce Flame is an action that starts it). The later action is the `feature.requires-effect` block until the spell is up, and rolls at that level (read through `effectiveActions`), so Spiritual Weapon from a level 3 spell slot hits for 2d8 plus the modifier. A player's console offers it only while the spell is up; an area's save is never a player's tap. A sheet built before the cast was an action isn't asked to cast it first.
67. **Heat Metal.** Its damage lands with no save; the creature holding or wearing the object then makes a Constitution save to keep hold (`onSuccessEffect`): keeping hold brings Disadvantage on attack rolls and ability checks until the start of the caster's next turn, and a failure tells the table the creature drops the object if it can (one that can't, in armor it wears, is the GM's to give the Disadvantage). The Bonus Action on later turns deals the damage again at the cast's level and asks again.
68. **Mage Armor ends when its creature dons armor.** Equipping body armor (`character.set-inventory`) ends the effect, which the table is told; a Shield doesn't, since it still adds to Mage Armor's AC.
69. **Healing outside a fight.** A heal used with no fight running (a potion, a healing spell, Second Wind, Lay on Hands' points) lands on the creatures picked with it (`action.use`'s `targetIds`), its user when none are or when it heals only its user, through the fight's hit point path: the dead stay dead (refused before anything is spent when everyone picked is), healing from 0 wakes, and temporary hit points are untouched. A player heals their own character or another member of the party (a public player character still on the roster), and a creature outside that is refused with one message that never names it; the GM heals anyone. One use heals one creature, a healing spell's count (`healTargets` on the action's availability row, Prayer of Healing's five) or any number for a divided pool. The sheet asks who regains the hit points, and Lay on Hands' points to spend. Damage outside a fight stays the GM's.
70. **A reaction spell on a Spell Scroll.** A scroll's cast action carries its spell's trigger (Shield's `ac-bonus`, Hellish Rebuke's `strike-back`), so the table offers it when the trigger happens, as the caster's own spell would be: only to a reader who can read the scroll (the legibility check now runs on a reaction offer too), with no slot. Used, the scroll is gone, and a spell above the reader's levels rolls its check first, a failure losing the spell (no AC for Shield) with the scroll.
71. **Speeds a spell or an item grants.** A `special-speed` modifier (`movement`: fly, swim, climb or burrow; `feet`, or `equalToSpeed`; `hover`) gives a creature a special speed while its carrier lasts, read live by the movement rules beside the stat block's and Roving's (`specialSpeedsOf`): Fly's 60 feet and hover, Spider Climb's and Freedom of Movement's Climb and Swim Speeds equal to Speed, Longstrider's +10 Speed (a `speed` modifier), a Ring of Swimming's 40 feet, Slippers of Spider Climbing, Winged Boots' charge and a Potion of Flying (each an hour the bearer ends on the sheet). "Equal to your Speed" follows Speed as it changes; walls, ceilings, and a broom or carpet stay with the GM.
72. **Ready.** A spell is readied by resolving its cast with `ready`: it must have a casting time of an action (not a Bonus Action, a ritual or a minute), the action and its slot are spent now, and the caster holds "Concentrating on X (readied)" and "Readied: X" (`EffectInstance.readiedSpell`, its action and level) until the start of its next turn, one cast, so breaking the Concentration dissipates it. Casting it off-turn releases it with the Reaction at the readied level, spending no slot; any other release (a different action, a move) dissipates it. A Readied creature's move off its turn is its Reaction: up to its Speed, counted apart from the turn's movement with no GM permission needed, and it uses up the ready. The player's console asks what is readied, and their sheet resolves actions off-turn while Readied; the held spell's level reaches only its caster's player.
73. **Halved Speed and the next attack roll.** Effects the engine reads by tag: `speed-halved` halves Speed after every other change, rounded down, special speeds too, and two such effects halve it once; `until-own-attack` lasts until its bearer's own next attack roll, hit or miss (Vicious Mockery's Disadvantage); `until-attacked` on an effect that holds more than the Advantage (Stunning Strike's halved Speed) gives up only its incoming-attack roll mode and keeps the rest until its own end; `slowed` (Slow) allows an action or a Bonus Action on its bearer's turn, never both, one attack with the Attack action (a spell's own attacks and a monster's Multiattack excepted), and a spell with a Somatic component fails on a d4's 1, its slot and action spent. A save's `failureEffect` carries its printed duration and an `armorClassBonus` that may be a penalty (Slow's -2, read by `armorClassInPlay`), and a save's `successEffect` is what a success leaves instead (Stunning Strike), parked on the pending save as `onSuccessEffect`. A feature's save may declare both.
74. **Damage that drains, and spells that end conditions.** An action's `drain` says what its damage takes besides hit points as it lands: `reducesMaximum` lowers the target's Hit Point maximum by the damage taken (one "Hit Point maximum reduced" effect holds the loss, `hitPointMaximumLoss`, and gives it back when it ends; a Long Rest ends it; a creature whose maximum reaches 0 dies), `heals` gives the dealer all or half of it, `damageType` counts that type alone, `keepsOneMaximum` stops at 1 (Harm) and `failedSaveOnly` drains only on a failed save. It is read from stat-block prose (`drainOfProse`: a wraith's Life Drain, a vampire's Bite) and set on Vampiric Touch and Harm. It lands on every path damage takes: a player's direct hit or the GM's acceptance of its proposal (`pendingDamage.drain`), a save's damage (`PendingSave.drain`, GM-only), a reaction's strike, and the GM's apply, which names the action (`sourceActionId`, from the resolution's `actionId`) so the server reads the drain off the source's own sheet; a player's apply never drains. Players never see the amount on the effect, and a monster's lower maximum and its healing are narrated to the GM alone. A spell's cast model may end conditions on its targets (`endsConditions`: Heal, Mass Heal, Power Word Heal, Protection from Poison), or the one the caster picks (`endsOneCondition`, Lesser Restoration, offered as the action's `conditionChoices` and sent as `conditionId`; the first present when none is named). A cure that only cures is refused on a creature with none of its conditions; one that also heals or protects still lands. `healing.toMaximum` restores every hit point (Power Word Heal).
75. **Pushes and bursts.** A save's `failurePush` (Thunderwave's 10 feet, a dragon's Repulsion Breath, read from the failure clause) rides the pending save, GM-only, and a committed failure pushes the creature the whole distance straight away from the save's source on the live map (`save.answer` hands the save its `pushToken`); a creature larger than `maxTargetSize` stays put, and a map that can't place it gives the GM a "move the token" line. A hit's pushes join the Push mastery's on the same offer and choice: an action's `onHitPush` (a fire giant's Hammer Throw, read from attack prose) and Repelling Blast's 10 feet on a Large or smaller creature, with the cantrip the Warlock picked for it read off the sheet. Eldritch Spear adds 30 feet a Warlock level to the picked cantrip's spell attack range, and Eldritch Mind gives Advantage on Concentration saves. An action's `burst` (Ice Knife) goes off after its attack, hit or miss: its damage is rolled once and the target and each combatant the map puts within `radiusFeet` of it, the attacker too, owe the save at the caster's DC (`diceAddedPerSlot` more dice a slot level up); with no map only the target owes it and the GM is told to add the rest.
76. **Temporary Hit Points, a higher maximum, and immunity from an effect.** `healing.temporary` makes a heal's roll Temporary Hit Points, which a creature takes only when they beat what it has (False Life, 5 more a slot level up through the spell's `healing.perSlot`; Tireless; Wild Shape's equal to the Druid level, through `adds.classLevel`). An action grant may carry `temporaryHitPointsEachTurn` (a number, or the caster's spellcasting ability modifier, fixed when the spell is cast), which the bearer gains at the start of each of its turns the same way (Heroism), `conditionImmunities` its bearer has while it lasts (Heroism's Frightened, read where every condition lands), and `hitPointMaximumGain` (Aid's 5, `perSlot` more a slot level up), which raises the bearer's Hit Point maximum and current hit points when it lands, a refresh adding only the difference, and takes the maximum back when it ends; a Long Rest ends it. Players never see these amounts or immunities on the effect. Tireless also takes a level of Exhaustion off at the end of a Short Rest.
77. **Species traits in play.** Dwarven Resilience, Fey Ancestry and Brave give Advantage on saves against the condition they name (`versus-condition` on `on-saving-throw`), and Gnomish Cunning on Intelligence, Wisdom and Charisma saves. A check now carries the conditions it would end (`CheckContext.stakes`; escaping a grapple passes the holding effect's linked conditions), so Powerful Build's Advantage on the check to end Grappled is read like a save's. Relentless Endurance holds an Orc reduced to 0 Hit Points, but not killed outright, at 1 Hit Point. That spends its once-a-Long-Rest use the first time it can. Adrenaline Rush is a Bonus Action Dash with Temporary Hit Points equal to the Proficiency Bonus (a feature action's `adds.proficiencyBonus`), Draconic Flight a Fly Speed equal to Speed for 10 minutes, and Large Form +10 feet of Speed and Advantage on Strength checks; becoming Large on the map stays the GM's.
78. **Magic weapons against creature types, and spell attack bonuses.** The attack's rider context carries the target's creature type from its stat block (a character has none), so a weapon's `extra-damage` gated on `versus-creature-type` lands: Dragon Slayer's 3d6 and Giant Slayer's 2d6 of the weapon's own type, Holy Avenger's and Mace of Disruption's Radiant against Fiends and Undead; Mace of Smiting adds +2 against a Construct and 7 Bludgeoning on a Critical Hit (14 against a Construct), and Vicious Weapon 2d6 on every hit. `spell-attack-bonus` is read now: `effectiveActions` folds it into the bonus of the bearer's spell attacks (Wand of the War Mage, Staff of Power, Staff of the Magi, Staff of the Woodlands, the two talismans), and no rider type is left unread.
79. **Protections a spell leaves.** Grants now carry Stoneskin's Resistance, Blur's Disadvantage on attacks against the caster, Divine Favor's 1d4 Radiant on weapon hits and Foresight's Advantage on D20 Tests with Disadvantage on attacks against its target. Barkskin (`barkskin`) raises an AC under 17 to 17 as it lands, as Mage Armor measures its own. Death Ward (`death-ward`) leaves its bearer at 1 Hit Point the first time it would drop to 0, and ends. A failure's `no-spells` (Befuddlement) refuses spells and the Magic action (`condition.no-spells`, economy). A save's `ongoingDamage` with no condition rides a declared failure effect (Vitriolic Sphere's 5d4 Acid at the end of the target's next turn), and a cast that deals no damage of its own scales that damage when upcast (Ensnaring Strike's 1d6, escaped with Athletics). `advantageAtSize` gives a creature that size or larger Advantage on the save (Ensnaring Strike's Large).
80. **Conditions a grant holds, choices a grant takes, and riders that read the attack.** An action grant's `conditions` are linked to its effect and end with it (Greater Invisibility; Nature's Veil until the end of the Ranger's next turn). `until-it-acts` (Invisibility) ends the effect once its bearer makes an attack roll, deals damage or casts a spell, a grant from that same resolve excepted, and ends the caster's Concentration once no creature keeps the spell. `enhanced-ability` (Enhance Ability) gives Advantage on checks with the ability the caster sends, any but Constitution, and `resists-chosen-type` (Protection from Energy) Resistance to the damage type it sends, one of the action's `damageTypes`. Dragon Wings is a Fly Speed of 60 feet until dismissed. A target's incoming-attack riders see the attack's kinds (Escape the Horde's Disadvantage on Opportunity Attacks, Spellguard Shield's on spell attacks), and an effect the attacker put on the target is read for its `by-effect-source` riders (Multiattack Defense, marked after a hit on the attacker's own turn and ended with that turn). A Rage that starts ends the conditions it now makes its bearer immune to (Mindless Rage). While raging, Primal Knowledge makes an Acrobatics, Intimidation, Perception, Stealth or Survival check a Strength check when that is the better roll, Advantage counted as +5. Potent Spellcasting adds the Wisdom modifier to the damage of the class's damaging cantrips, named by id.
81. **Areas, later turns and readied rays.** An area template takes the action's own area: the GM's drag places it and points it, and its shape and size are the area's (`templateOfArea`: a Sphere's, a Cylinder's or an Emanation's radius, a Cone's or a Line's length, a Cube's side), so a short drag still makes Fireball a 20-foot-radius Sphere, and a lingering area the GM places later (`spell-zone.place`) is its zone's own area; the GM's preview mirrors it. A Cylinder is kept as one (`cylinder`, drawn as the circle of its radius). What a spell offers "on your later turns" (`laterTurnsOnly`: Spiritual Weapon, Heat Metal, Arcane Sword, Conjure Fey, moving Hex) is refused on the turn of its cast (`spell.later-turn`), read from a `turnUses` mark the cast leaves. A readied spell of several rays keeps its ready until its last ray, all on the one Reaction (`readiedSpell.raysLeft`). A heal used outside a fight tells its user who regained what (`healing` on the loose reply). Worn armor's Strength need and Stealth Disadvantage are read from the catalog's armor block when a row names the item only.

## Mobile, security, and visibility impact

All validation, rolls, and effect lifecycle run server-side; phones and desktops see identical outcomes. Blocked rows stay tappable in the GM UI: the server rejection opens the one-tap override dialog, so the client never gates (server authority, CLAUDE.md rule 2). New projection fields are explicit allowlists: effects reach players without source actor/action ids (hidden sources masked as "A hidden threat"), a hidden combatant's turn instance and per-turn uses project as idle, limited-use spending travels only to the owning player, a player's `rest` view carries only their own characters' Long Rest requests and Short Rest place (never the clock or `lastLongRestAt`), and the public viewer projection is unchanged.

## Migration / reversibility

All state additions are additive-with-defaults on schemaVersion 1: existing campaigns, turn snapshots, and archives parse unchanged, and old journals replay under `freeform` mode. The bundle regeneration is deterministic and reviewed in git. Reverting enforcement is a one-line default change (`rulesMode` to `freeform`) with no state migration; removing the mechanics fields would require a content-schema review per ADR-007.
